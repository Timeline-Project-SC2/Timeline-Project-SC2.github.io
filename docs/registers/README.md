# Регистры: ошибки, баги, решения, TODO

Регистры — сквозные документы. Этапные записи живут в
[`../stages/`](../stages/README.md), сюда выносится только то, что повторяется
или касается нескольких этапов.

| Файл | Что внутри | Лимит |
|---|---|---|
| [`errors-systemic.md`](errors-systemic.md) | Систематические ошибки проектирования и процесса. Единственный документ без лимита строк (решение владельца) | без лимита |
| [`bugs-infra-ci-and-sandbox.md`](bugs-infra-ci-and-sandbox.md) | Мерж, rulesets, GitHub Actions, красные проверки, образы раннеров; песочница, потеря работы, гонка инструментов, headless-браузер, UI-индикаторы | 200 |
| [`bugs-data-and-contracts.md`](bugs-data-and-contracts.md) | Google Sheets, `sync.py`, `meta.json`, растр, типы мест, единицы измерения | 200 |
| [`decisions.md`](decisions.md) | Индекс сквозных решений (`И-*`, `A-*`, `D-*`, `Z-*`, `SW-*`, `F-*`) со ссылками на этапы | 200 |
| [`todo.md`](todo.md) | Общая очередь работ, разблокировки и зависимости | 200 |

## Как добавить запись

1. Проверьте, не описан ли случай уже — поиск по ID и симптому.
2. Если случай локальный для этапа, пишите в секцию «Ошибки» или «Баги»
   паспорта `stages/stage-NN/plan.md` (при росте секции — в вынесенный
   файл этапа). В регистр выносите только повторяющийся паттерн.
3. Формат записи: `ID · дата · симптом · причина · что делать · источник`.
4. Закрытая запись не удаляется: добавляется «закрыто» с датой и ссылкой
   на PR/коммит.
