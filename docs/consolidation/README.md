## 4. Правила, которые остаются в силе

- Паспорт этапа един; регистр выносится в файл при росте секции > ~60
  строк или самостоятельной цитируемости, пустым этапам не заводится.
- Файл — до 200 строк и один цельный контекст темы; контекст больше
  200 делится по смысловой границе в своей среде (этап, домен, папка).
- Читать документацию — по глубине кратной диверсификации: не глубже
  3 переходов от файла задачи, стартовый набор ≤ 6 документов и
  1 000 строк (см. [`consolidation-plan.md`](../consolidation-plan.md) §6.2).
- Имена новых файлов — по предмету: без суффиксов частей, `-note`
  и дат; переезд — только в контексте конкретной задачи, с редиректом
  на старом пути при внешних ссылках.
