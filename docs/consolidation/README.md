Действия в таблицах: **ОСТАВИТЬ** (цельный точечный контекст 60–200 строк
или защищённый путь), **СКЛЕИТЬ** (один целевой файл из перечисленных),
**СЕКЦИЕЙ В ПЛАН** (гибрид регистров), **ПЕРЕЕЗД** (только с обоснованием
конкретной задачи и редиректом при внешних ссылках), **УДАЛИТЬ-ДУБЛЬ**
(после построчной сверки, что текст уже живёт в целевом файле),
**ПЕРЕРАЗБИТЬ** (объём > 200: деление по смысловым заголовкам H2, а не
по счётчику строк). Оценка «~N» — тело без повторяющихся шапок «Назад».

## 4. Правила исполнения, вшитые в карту

- Очереди строго отдельно: **P0** — гигиена на месте из
  [`inventory-orchestration-prompts.md`](inventory-orchestration-prompts.md)
  §4; **P1** — склейки внутри папок по кластерам частей 2–5; **P2** —
  гибрид паспортов, переезды и переименования по предмету.
- Каждая склейка проектируется на 120–170 строк; если сборка паспорта
  этапа даёт > 190, крупнейший регистр сразу выносится обратно в файл —
  это штатный механизм гибрида, а не нарушение карты.
- Глубина чтения при исполнении — по правилу `consolidation-plan.md` §6.2:
  не глубже 3 переходов, стартовый набор ≤ 6 документов / 1 000 строк.
  Шаг 0 этому правилу не противоречит: замеры выше — машинный подсчёт
  метража и графа, а не чтение тел документов.
- После каждой папки: коммит, пуш, `check_docs.py`, граф сирот = 0 новых,
  прыжков заголовков не больше базиса 51.
- Рабочие бумаги шага 0 (эта папка, кроме данного хаба) после закрытия
  P2 удаляются; хаб остаётся как журнал консолидации.

## 5. Что нужно от владельца сейчас

Одно решение по карте: **«да»** целиком, **«да, кроме …»** со списком
вычеркнутых кластеров или правки оценок. До этого решения исполнителю
разрешено только готовить очередь P0 внутри её списка; перемещения,
склейки и удаления не начинаются.
