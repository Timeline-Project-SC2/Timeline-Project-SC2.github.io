# Гайд игроку: что прислать про свою планету

Справочник для игроков: какие данные о своём мире нужно передать, чтобы
планету сгенерировали и построили для неё карту, глобус и досье.
Разбираться в инструментах не нужно — достаточно ответить по-человечески.

Минимум — четыре ответа: название, система, тип мира, размер.

| Что | Как ответить |
|---|---|
| Название и система | Аквилон, система Аквилон |
| Тип мира | обитаемый / океан / пустыня / лёд / вулканы / мёртвый мир / газовый гигант |
| Размер | как Земля / как Марс / радиус 4200 км |
| Вода | сколько % поверхности |
| Климат | холодно / умеренно / жарко; где пустыни, где леса |
| Рельеф | гор много или мало; материки крупные или острова |
| Сутки и ось | 24 ч, наклон 23° — можно не указывать |
| Референсы | 1–3 картинки + имена с карты дословно |

**Не присылать:** seed, `generation_key`, версии генератора, координаты
`x`/`y`, 37 колонок профиля — это выдаёт и собирает инструмент.

**Получишь:** три варианта A/B/C, глобус, три ракурса, карту с подписями
и досье. Карта — иллюстрация, а не измерительный эталон.

Если планеты ещё нет в каталоге, её добавляет команда проекта: игрок
называет мир и систему, остальное — за инструментом.
