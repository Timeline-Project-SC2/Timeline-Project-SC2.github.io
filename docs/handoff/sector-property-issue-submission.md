## Формат пакета v2

Браузер отправляет черновик без автора и времени:

```json
{
  "type": "sector-property-request-draft",
  "version": 2,
  "requestId": "pr-<время>-<случайность>",
  "threadId": "pr-<нить>",
  "baseRevision": "<64 hex>",
  "changes": [
    { "dataset": "systems", "recordId": "1", "field": "description", "before": "старое", "after": "новое" }
  ]
}
```

Сервер запечатывает автора из сессии, время UTC и приватную цель. Тело Issue:
шапка «кто / когда / что меняется», нить и база, затем строки «было → стало»
и канонический JSON между маркерами `<!-- sector-property-request:v2:begin -->`
и `<!-- sector-property-request:v2:end -->`. Другой порядок ключей, пробелы,
CRLF и посторонний текст вокруг блока отклоняются.

Ограничения: до 100 изменений, до 50 объектов, значение до 4000 символов
(`source_url` — до 2048), тело до 60 000 байт. ID, координаты и связи не
редактируются этим контрактом.

## Нити, версии и квота

- `requestId` уникален для версии; `threadId` связывает версии одной заявки.
- Первая версия создаёт Issue. Следующая версия добавляется комментарием в ту
  же нить; тело и заголовок прежней Issue не перезаписываются.
- Закрытая нить не принимает новую версию. Закрытие не доказывает применение.
- Квота считает открытые нити, а не версии. Значение `PROPERTY_OPEN_LIMIT`
  задаёт владелец (1–20); без него приём выключен.
- Неизвестный результат создания держит резерв: немедленный повтор не идёт в
  GitHub, затем восстановление ищет уже созданную заявку.

## Безопасность канала

Вход запрашивает только личность (`scope=''`); токен пользователя не хранится.
Cookie сессии — `SameSite=None; Secure; HttpOnly`, срок 7 суток. Изменяющие
маршруты требуют точный `Origin`, JSON-тело и сессию; preflight без wildcard.
Секреты App и OAuth задаются только в Cloudflare.

## Чего это не делает

- Не проверяет роль Owner и не применяет правку.
- Не пишет `data/sector-property-overlay.json` и не публикует сайт.
- Не показывает чужие заявки и не даёт игроку ссылку в приватный репозиторий.
- Не реализует «Отложить», «Отозвать» и причины отказа: решения владельца нет.

## Перед включением

1. Владелец подтверждает приватный репозиторий, App, установку и лимит.
2. Секреты задаются в Cloudflare, не в репозитории и не в чате.
3. Сборка сайта получает `ATLAS_ISSUE_GATEWAY_URL`.
4. Отдельное разрешение на пробную живую Issue.
5. Применение и публикация остаются выключенными до следующего этапа.
