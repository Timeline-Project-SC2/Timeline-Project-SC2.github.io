### 17.25. Задача `Z-4f`: фактическая сетка адресов (26.10.2026)

> **Статус 26.10.2026:** контракт этого раздела вошёл в версию 4.0 гайдлайнера (§17.3) и
> выдан карточкой **`F-3`** (§18.4); числа §17.25.3 ниже остаются расчётной базой, но
> источником истины считается §6 и §17.3 гайдлайнера.

Владелец: «надо добавить сетку, как сейчас фон — но фактическую… сейчас она есть и имеет в
углу адрес, вот надо такую же, состояние в зависимости от глубины приближения, ещё и чтобы
не выглядело как-то дерьмово»; уточнение спецификации: «Фактическая, не ложная, не
абстрактная, **одна толщина** и каждая сетка как бы **вложена друг в друга**. Подсветка
самой большой на текущем виде, показывать **один уровень `−1` глубины**».

#### 17.25.1. Что есть сейчас (проверено по `main = 3611b54`)

| Слой | Где | Факт |
|---|---|---|
| `.map-grid-overlay` | `site/shared/styles.css` | декоративная CSS-сетка, шаг всегда `80 px`, `opacity .12` — **ложная**, от масштаба не зависит |
| `gridFor` → `drawGridLine` | `sector-scene.ts` + `canvas-renderer.ts` | одна толщина `1 px`, **один** цвет `rgba(150,180,215,.10)`; сетка только `L1…L9` |
| `drawGridLabel` | `canvas-renderer.ts` | `9 px`, цвет `rgba(160,186,216,.42)`, смещение `+3/+3 px` от угла ячейки |
| Тир | `GRID_TIER_BY_LEVEL = [null,1,1,2,2,2,2,3,3,3]` | жёсткая таблица по уровню, скачок без перехода |

Отсюда два дефекта вида: линии без отношения друг к другу (нет «старший/вложенный»),
и поверх живой сетки лежит второй, фоновый шаг `80 px`, который ни на одном уровне не
совпадает с фактическими ячейками.

#### 17.25.2. Контракт `Z-4f`

1. **Одна толщина.** Все линии — `1 px`, без иерархии по толщине. Различие только
   прозрачностью.
2. **Вложенность.** В кадре одновременно две сетки: тир текущего вида (`t`) и ровно один
   тир глубже (`t + 1`), вложенный в каждую ячейку. Глубже `t + 1` не рисуется.
3. **Подсветка старшего.** Линии `t` — ярче (`alpha ≈ .16`), линии `t + 1` — тише
   (`alpha ≈ .07`). Глубже — не ярче старшего, никогда.
4. **Фактическая геометрия.** Линии строятся по границам ячеек из `ADDRESS_TIERS`
   (мировые координаты → экран), а не по экранной решётке. При панорамировании линии
   едут вместе с картой, при зуме — пересчитываются.
5. **Тир от размера ячейки, а не от номера уровня.** Правило: самый крупный тир `t`,
   у которого ячейка на экране `≤ 450 px`, а вложенная `t + 1` `≥ 16 px`. Таблица
   «уровень → тир» (`GRID_TIER_BY_LEVEL`) удаляется.
6. **Адрес в углу ячейки** остаётся (это то, что владельцу нравится), но подпись рисуется
   с тёмным контуром (`strokeText`, `2 px`) вместо плашки — пелены нет. Порог влезания
   `loupeLabelFits` (`2 + 5,4 · длина ≤ cellPx`) **не ослаблять**.
7. **Фоновая `.map-grid-overlay` удаляется** из `styles.css` и разметки: остаётся одна
   сетка — фактическая.
8. **Предохранители не поднимать:** `MAX_GRID_LINES = 512` (по `§17.25.3` максимум `~218`),
   `MAX_GRID_LABELS = 64`. При превышении — сетка деградирует до одного тира `t`.
9. **Плавность.** При смене тира — гаснет/проявляется `160` мс; при
   `prefers-reduced-motion` — мгновенно. Новых слоёв и второго canvas не делать
   (Дельта 2, 25.10.2026).

#### 17.25.4. Приёмка `Z-4f`

- На `L0…L12` сетка есть на всех уровнях, включая `L0` и упор.
- В кадре видны ровно два тира: старший ярче, вложенный тише; третьего нет.
- Ячейки совпадают с миром: панорамирование не «скользит» линии относительно узлов.
- Декоративной сетки `80 px` в разметке нет.
- Наложения подписей нет (`loupeLabelFits`), подпись читается на заливке территории.
- `verify:sector-core` — `0` отказов, `MAX_GRID_LINES`/`MAX_GRID_LABELS` не подняты.
