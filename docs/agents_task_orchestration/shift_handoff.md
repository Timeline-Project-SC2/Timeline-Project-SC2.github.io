## 4. Первые десять минут смены (шаг 0)

1. `git rev-parse --abbrev-ref HEAD` — ветка сессии, никогда не `main`; `git status --short` — чисто.
2. `git fetch -q origin main && git log --oneline -1 origin/main` — ожидается `699896c` или новее.
3. Снять статус CI последнего слитого PR (`gh pr checks <N>`); норма теперь — **4/4 зелёных**.
   Локально Гайдлайнер код не запускает (О-5); единственное исключение — `npm run verify:docs`.
4. Факты о коде — только спецификацией поиска воркеру (вопрос, пути, формат `путь:строка`,
   лимит строк). Самому `src/`, `tests/`, `tools/`, конфиги не открывать (урок E-11).
5. Только после этого — постановка `F-4`: сначала спецификация, затем docs-PR карточки
   (`F-4.md` + `F-4-execution.md` по образцу F-3), затем промпт воркеру в отдельный чат.

## 7. Как проверять и как сливать

- О-5: статусы только через CI и отчёт воркера/`rc-04`; свои — `git diff --check` и
  `npm run verify:docs` (лимит 200 строк, один H1, живые ссылки, нет файлов-сирот).
- Зелёные обязательны: `typecheck`, `lint`, `build`, `verify:publish/address/sector-core/no-raster`,
  `check:planet-core` — теперь все реально исполняются в CI (9 шагов джобы «Скрипты сайта»).
- `npm test` — это страж карантина (`tools/check_test_baseline.mjs`), два прогона; red-секции
  «НОВЫЕ ПАДЕНИЯ» и «КАРАНТИН НЕ ПРИМЕНЁН». Реестр — `tools/known-test-failures.json`,
  условие снятия — `S8-Q1`. Менять реестр можно только решением владельца.
- Красная джоба — сигнал поломки, а не норма; `--admin` остаётся только из-за ruleset ветки.
- Слияние: `gh pr merge <N> --squash --admin`. `BLOCKED` в `gh pr view` — ожидаемый ruleset;
  детали — [`handoff/infra-pitfalls.md`](../handoff/infra-pitfalls.md).
- Каждая карточка закрывается docs-PR вердикта (статус «принята», журнал, индекс README);
  исторические вердикты не переписывать — новые режимы фиксировать блоком преемственности.

## 8. Грабли, на которых уже теряли время

- **Shallow-клон:** `git fetch --deepen=5 origin main`; при `unrelated histories` и чистом
  дереве — `git reset --hard origin/main`.
- **Логи Actions:** `gh run view --log-failed` часто пуст; точка отказа —
  `gh api .../actions/runs/<id>/jobs` с фильтром `conclusion=="failure"`.
- **Параллельные fetch перетирают `FETCH_HEAD`:** ветку воркера тянуть в именованный реф
  `git fetch origin <branch>:refs/remotes/worker/<short>` и diff'ать против него.
- **Draft PR:** перед merge `gh pr ready <N>`; иначе merge ответит «still a draft».
- **`gh pr edit` падает на Projects classic:** тело PR править через
  `gh api .../pulls/<N> -X PATCH --input -`.
- **Посторонняя иероглифика в авторском тексте:** перед коммитом прогонять python-сканер
  диапазонов `0x3000–0x9fff`, `0xff00–0xffef` по изменённым `.md` и телу PR (сбой этой смены
  повторялся многократно). Известная чужая опечатка: в `stage-03/plan.md:20` слово «адрес»
  набрано катаканой — чинить отдельным мелким docs-PR, не в карточке волны.
- **Параллельные инструменты:** не смешивать запись файла и зависимое чтение в одном блоке.
- **Ручные `?v=`** в HTML/TS запрещены: хэши ставит сборочный конвейер.
