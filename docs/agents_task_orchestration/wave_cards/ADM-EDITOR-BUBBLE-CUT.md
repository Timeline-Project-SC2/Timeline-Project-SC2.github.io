## 1. Цель: что именно «вырезаем»

Убрать из **отрисовки** слой баблов-выделений, которые строятся относительно выбранных систем: мягко сливающиеся окружности/«лепестки», обводка и заливка, чьи форма, радиус или видимость зависят от текущего выбора системы или группы систем. Исторический слой фракционных сетей (`Z-3.4`, баблы/узлы/поля/каналы/всполохи) по [очереди сектора](../../stages/stage-09-12-sector/todo.md) уже выведен из рендера; если он всё ещё проявляется при выборе системы — это и есть цель, точное место зафиксировать в отчёте.

**Не трогать:** маркеры систем и их цвета, подписи, границы сектора и туманностей, пунктир гало как данные/модель, кривые границ, `data/sector-bounds.json`, исторические `net_id`/`net_confront_id`, `sector-gradient.ts`, выбор системы, полёт, стрелки, карточку точки, зум/пан, админ-панель и её условный код.

**«Вырезание» = отключение визуального выхода слоя** и удаление ставшего мёртвым кода только в зоне задачи. Модули, данные, геометрию и публичные API **не удалять**: по [концепции взаимодействия модулей](../../concepts/module-interaction-rules.md) редактор работает с исходными модулями, а не с их копиями, и ED-2 подключает их как модели. Если слой используется и в редакторе, оставить модель и экспорт, убрать только вызов в боевом рендере.

## 4. Режим проверок: только критический минимум

**Решение владельца 05.11.2026:** полный набор тестов и проверок на текущем этапе **убирается** — он сильно замедляет работу. Разрешены только проверки, критичные для работоспособности сайта и функций редактора:

| # | Оставить | Почему критично | Порог |
|---|---|---|---|
| 1 | `npm run build` | она же проверяет типы (`tsc --noEmit`) и собирает статику; красная сборка = сайт не открывается | падение сборки чинить **сейчас** |
| 2 | Ручной smoke, 2–3 минуты, без автоматизации: `/` и `/sector/` открываются без белого экрана и ошибок в консоли; выбор системы работает; баблов-выделений нет; границы, маркеры, подписи, зум/пан на месте; `/sector/admin-edit/` открывается, панель не сломана | прямое подтверждение, что сайт и редактор живы | белый экран/ошибка консоли чинить **сейчас** |
| 3 | `git diff --check`, `git status --short`, `git diff --name-only origin/main...HEAD` | дешёвый контроль, что затронуты только свои файлы | чужой файл — вернуть |

**Не запускать сейчас, не добавлять новых тестов:** `npm test`, `npm run test:py`, `npm run lint`, `npm run build:wasm`, `npm run verify:publish`, `npm run verify:contract`, `python3 tools/sync.py --strict`, `python3 tools/planet_generation.py validate`, `python3 tools/build_assets.py --check`, бенчмарки и замеры кадра, headless-браузерные сценарии, проверки доступности/клавиатуры/телефона, красную тему, визуальную приёмку владельцем, независимого критика, повторную сверку CI 4/4.

**Не править** `package.json`, `check.yml`, ruleset и настройки репозитория ради ускорения; CI на PR запускается GitHub сам — локально его не ждём и не считаем своей проверкой. Некритичные падения в CI записать в `TODO`, критическое падение сборки починить. Найденные, но не связанные с задачей дефекты не чинить, а пометить `TODO`.
