## 1. Цель и проверяемые критерии готовности

Сделать так, чтобы восемь планетарных падений не появлялись ни в выводе `npm test`, ни в
отчётах: skip-флаги раннера строятся из единого реестра, а страж следит, чтобы карантин был
применён точечно и не маскировал ничего нового.

**Готово = одновременно:**

1. `npm test` (вызов стража) завершается с кодом `0`; карантинный прогон не содержит ни одной
   строки `not ok`, а число тестов в нём ровно на 8 меньше, чем в полном. TAP-строк `# SKIP`
   нет by design: runner-level фильтрация убирает тест до исполнения (редакция CI2-7), «пропуск»
   здесь означает отфильтрованный тест, а не TAP-skip. Полный нефильтрованный прогон доступен
   как `npm run test:raw` и по-прежнему показывает те же 8 падений (аварийный люк сохранён).
2. Страж работает в два прогона (§4.2, CI2-7) и краснеет при (а) любом `not ok` вне реестра в
   полном прогоне, (б) имени реестра, которое в полном прогоне не падает (починка/переименование),
   (в) `not ok` в карантинном прогоне или невыполнении арифметики `N2 = N1 − 8` (сломанный или
   широкий skip-паттерн), (г) крэше любого из процессов без TAP-итогов. Зелёный — только при
   согласии обоих прогонов.
3. Реестр `tools/known-test-failures.json` получает блок `meta` с явной пометкой о намеренном
   временном карантине этапа 8 и условием снятия; восемь TAP-имён не меняются.
4. `.github/workflows/check.yml`: число шагов джобы `scripts` остаётся 9, шаг тестов
   переименован под карантин, поясняющий комментарий переписан; CI PR — 4/4 `success`
   (доказательство jobs API).
5. Исходники трёх планетарных тест-файлов и весь `src/` не тронуты;
   `git diff --name-only origin/main...HEAD` — ровно 5 файлов из §3.
6. Self-test стража переписан под два TAP-потока (полный и карантинный) и зелёный;
   `verify:docs`, `diff --check` чистые.

**Не входит:** починка восьми тестов и снятие карантина (это пункт `S8-Q1`, контур `rc-02`),
правки самих тест-файлов, изменение списка из 37 тест-файлов, новые ESLint-правила, правки
других workflow.

### 4.2. Страж `tools/check_test_baseline.mjs` — два прогона (редакция CI2-7)

Факт шага 0: в Node 22/24 `--test-skip*` отфильтровывает тесты **до исполнения**, TAP-строк
`# SKIP` не возникает и счётчик skipped равен 0. Поэтому страж дважды запускает одну и ту же
команду, собранную из `scripts["test:raw"]` (свой список файлов запрещён), с TAP-репортёром.

**Прогон 1 — целостность, без skip-флагов.** Код выхода процесса не используется как сигнал
(восемь падений ожидаемы); разбираются TAP-строки `not ok` с учётом вложенности подтестов:

- множество имён падений обязано совпасть с множеством реестра;
- имя вне реестра → exit 1, секция «НОВЫЕ ПАДЕНИЯ:» с именами (девятое блокирует, в т.ч.
  регрессия в не-карантинном тесте);
- имя реестра не найдено среди падений → exit 1, секция «КАРАНТИН НЕ ПРИМЕНЁН: устаревшие
  имена …» (тест починен или переименован — JSON обновляется тем же PR);
- снять число тестов прогона `N1` (по TAP-итогам/плану).

**Прогон 2 — карантин, со skip-флагами.** Имя флага определяется во время исполнения по
`node --help`: предпочтение `--test-skip`, откат на `--test-skip-pattern` (Node 22 локально);
ни одного флага нет — ошибка с понятным сообщением, маскировать запрещено. На каждое имя
реестра — отдельный флаг; паттерн есть экранированная полная TAP-строка имени, заякоренная
`^…$` (экранируются в т.ч. `(`, `)`, `#`, `·`, `≤`, `%`, кириллица). Требования:

- код выхода процесса `0`;
- ноль строк `not ok`;
- число тестов `N2 = N1 − 8` (арифметика доказывает, что отфильтрованы ровно восемь
  реестровых тестов и ни один другой; `skipped === 0` при этом нормален);
- любое невыполнение → exit 1, секция «КАРАНТИН НЕ ПРИМЕНЁН:» с указанием несошедшейся
  арифметики или `not ok`.

**Итог.** Зелёный исход `0` — только при согласии обоих прогонов. Строка лога:
«карантин этапа 8: прогон 1 — 8/8 реестровых падений; прогон 2 — отфильтровано 8, not ok 0;
новых падений нет». Крэш любого процесса без TAP-итогов — exit 1 отдельным сообщением, под
реестр не маскируется. Без сети, без `Math.random` и обращений к часам. Принятая цена: шаг
тестов примерно вдвое длиннее (CI2-7), другие 8 шагов джобы не меняются.

### 4.5. Self-test `tests/check-test-baseline.test.mjs`

Синтетические TAP-фикстуры двух прогонов (реальный набор не запускается): зелёная пара

прогона. Плюс разбор `test:raw` из `package.json`, экранирование спецсимволов в паттерне и
выбор skip-флага по выводу `node --help`.
