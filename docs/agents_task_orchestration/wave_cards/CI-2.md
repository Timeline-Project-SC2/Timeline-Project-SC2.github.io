## 1. Цель и проверяемые критерии готовности

Сделать так, чтобы восемь планетарных падений не появлялись ни в выводе `npm test`, ни в
отчётах: skip-флаги раннера строятся из единого реестра, а страж следит, чтобы карантин был
применён точечно и не маскировал ничего нового.

**Готово = одновременно:**

1. `npm test` завершается с кодом `0`; в TAP ровно 8 пропусков с именами из реестра
   (`# SKIP`), ни одной строки `not ok`. Полный нефильтрованный прогон доступен как
   `npm run test:raw` и по-прежнему показывает те же 8 падений (аварийный люк сохранён).
2. Страж (имя файла `tools/check_test_baseline.mjs` сохраняется) переведён в режим
   «карантин + целостность»: краснеет при (а) любом `not ok` вне реестра, (б) имени реестра,
   которое не нашлось среди пропусков (переименование/удаление теста, сломавшийся паттерн),
   (в) крэше процесса без TAP-итогов. Зелёный — только при точном совпадении множества.
3. Реестр `tools/known-test-failures.json` получает блок `meta` с явной пометкой о намеренном
   временном карантине этапа 8 и условием снятия; восемь TAP-имён не меняются.
4. `.github/workflows/check.yml`: число шагов джобы `scripts` остаётся 9, шаг тестов
   переименован под карантин, поясняющий комментарий переписан; CI PR — 4/4 `success`
   (доказательство jobs API).
5. Исходники трёх планетарных тест-файлов и весь `src/` не тронуты;
   `git diff --name-only origin/main...HEAD` — ровно 5 файлов из §3.
6. Self-test стража переписан под TAP с `# SKIP` и зелёный; `verify:docs`, `diff --check` чистые.

**Не входит:** починка восьми тестов и снятие карантина (это пункт `S8-Q1`, контур `rc-02`),
правки самих тест-файлов, изменение списка из 37 тест-файлов, новые ESLint-правила, правки
других workflow.

## 4. Контракт до буквы

### 4.1. `package.json`

- Добавить `test:raw` со значением **текущей строки `test` дословно** (`node --test
  --test-concurrency=1` и 37 файлов, включая `check-test-baseline.test.mjs`).
- `test` заменить на `node tools/check_test_baseline.mjs`. `test:all` и прочие скрипты не трогать.
- Единственный источник списка файлов — `test:raw`: страж парсит именно его, свой список не ведёт.

### 4.2. Страж `tools/check_test_baseline.mjs` (имя файла сохраняется)

- Читает `scripts["test:raw"]`, разбирает на аргументы, добавляет TAP-репортёр и skip-флаги.
- Skip-флаг определяется **во время исполнения** по `node --help`: предпочтение `--test-skip`,
  откат на `--test-skip-pattern` (так флаг называется в Node 22 локально); ни одного флага нет —
  ошибка с понятным сообщением, маскировать запрещено.
- На каждое имя реестра — отдельный флаг; паттерн есть экранированная полная TAP-строка имени,
  заякоренная `^…$` (экранируются в т.ч. `(`, `)`, `#`, `·`, `≤`, `%`, кириллица).
- Парсит TAP: пропуски (`ok … # SKIP`), падения (`not ok`), вложенность подтестов.
- Зелёный исход `0` только когда: `not ok` нет; каждое имя реестра найдено среди пропусков;
  число пропусков равно длине реестра (других skip в репозитории нет — подтвердить на шаге 0).
  Итоговая строка лога: «карантин этапа 8: 8/8 пропущено намеренно, новых падений нет».
- Красные исходы `1` с русскими секциями: «НОВЫЕ ПАДЕНИЯ:» (имена), «КАРАНТИН НЕ ПРИМЕНЁН:
  устаревшие имена …» (запись реестра не сматчилась), отдельное сообщение о крэше процесса.
- Без сети, без `Math.random` и обращений к часам — прогон детерминирован.

### 4.3. Реестр `tools/known-test-failures.json`

- Объект с блоком `meta`: назначение («намеренный временный карантин этапа 8»), дата решения
  владельца `2026-10-26`, ссылки на `S8-Q1` и карточку `CI-2`, условие снятия (починить и
  удалить запись; молча удалить нельзя — страж покраснеет).
- Массив `tests` из тех же 8 объектов с полями `name`, `file`, `contour`, `knownSince`;
  добавляется поле `reason` (короткая русская формулировка долга по `knownSince`).
  Порядок и имена — как в текущем файле на `main`.

### 4.4. `check.yml`

- Шаг «Тесты node:test со стражем базы» переименовать в «Тесты node:test с карантином этапа 8
  (страж целостности)», команда остаётся `node tools/check_test_baseline.mjs`.
- Комментарий шага переписать: карантин намеренный, реестр и пункт `S8-Q1`, красные пути стража;
  упоминания «базы падений» и старого обрыва блоков убрать. Остальные 8 шагов без изменений.

### 4.5. Self-test `tests/check-test-baseline.test.mjs`

Синтетические TAP-фикстуры (реальный набор не запускается): зелёный случай «8 skip, 0 not ok»;
красный — новое `not ok`; красный — имя реестра без пропуска; красный — лишний пропуск;
красный — крэш; разбор `test:raw` из `package.json`; экранирование спецсимволов в паттерне;
выбор skip-флага по выводу `node --help`.
