## Результат и следующий шаг

Воркер сообщил PR HEAD `38195e19461fd332a8f43ae258759d97fe9b96c2`, проверку YAML,
событий, прав, ограничения цели и веток отказа; фактического запуска App не было.
Гайдлайнер подтвердил Git-метаданными один новый workflow, CI 4/4 и слил #343 без
`--admin`. Merge в `main`: `979ff7e7780c0dcb27179f6aace26872509ad386`; GitHub
показывает workflow `Manual App owner check (read-only)`. Слияние штатно запустило
существующий Pages deployment; исходники и результат job Гайдлайнер не читал.

По отчёту воркера, переменная — `OWNER_CHECK_APP_CLIENT_ID`, секрет —
`OWNER_CHECK_APP_PRIVATE_KEY`, окружение — `app-owner-readonly`. Это **новые имена**,
не значения и не имена ранее существовавших секретов. Для будущего запуска владелец
сам создаёт окружение с выбранной веткой `main`, задаёт в нём Client ID и закрытый
ключ; ничего из этого в чат не передаёт. Пользователь и результат ручной проверки
публичны в Actions и могут косвенно раскрыть членство/роль. На момент слияния
размещение ключа и запуск ещё не были подтверждены; автоматическая запись по-прежнему
на `HOLD`, а зелёный CI не доказывает работу App. Существующие настройки, секреты и
рабочие данные помощник не менял.

## Первый запуск владельца

[Ручной запуск](https://github.com/Timeline-Project-SC2/Timeline-Project-SC2.github.io/actions/runs/41249127505)
шёл с `main` на `979ff7e` и завершился ошибкой: action получил пустой `client-id`;
до проверки роли дело не дошло. Правильность Client ID и ключа ещё не установлена.
GitHub API разрешил увидеть окружение `app-owner-readonly`, но показал отсутствие
ограничения веток (`deployment_branch_policy: null`); до повторного запуска владелец
должен настроить Selected branches → Branch `main`. Это не свидетельство утечки.

Точечные read-only запросы к одноимённой переменной окружения и репозитория вернули
`403`; существует ли она и чему равна, неизвестно. Практический следующий шаг —
сохранить **Client ID, не Client secret** в repository Actions Variable
`OWNER_CHECK_APP_CLIENT_ID`; закрытый ключ должен оставаться только environment
secret. Затем владелец может начать новый ручной запуск, не раскрывая значения.
Помощник настройки и секреты не менял и их содержимое не запрашивал.
