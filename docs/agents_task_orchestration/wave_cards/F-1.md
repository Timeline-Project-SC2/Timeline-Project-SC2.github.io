### 4.2. `src/atlas/level-ladder.ts`

```text

export const MIN_VISIBLE_WIDTH = 16000;
export const HYSTERESIS = 0.12;
export const LEVEL_STEP = 1.9194;                    // НОВЫЙ
export const DEEPEST_SECTOR_LEVEL = 12;              // было 9
export const MAX_SCALE = 1 / TARGET_LY_PER_PX;       // НОВЫЙ: 500 px/св.г.
export const MARKER_EXPONENT = 0.3544;               // было 1.1374
export const LAYER_FADE_STEP = 0.75;
export const LAYER_FILL_ALPHA_MIN = 0.25;
export const LAYER_LINE_ALPHA_MIN = 0.45;
export const DEEP_LAYER_FIRST_LEVEL = 2;
export interface LevelSpec {                         // addressLetters — БЕЗ ИЗМЕНЕНИЙ: 0|1|2|3|4|5
  readonly level: number; readonly id: string; readonly frame: 'S' | 'O';

}
export function levelSpec(level: number): LevelSpec;        // поиск по полю level, не по индексу
export function frameOf(level: number): 'S' | 'O';
export function visibleWidthForLevel(level: number): number;

export function levelForWidth(visibleWidth: number, prev?: number): number;   // 0…12
export function markerDiameter(visibleWidth: number): number;
export function maxScaleForTargetWidth(viewport: FrameViewport, mapSize: number, fitInset: number): number;
export function minScale(): number;
export function edgeDistance(viewport: FrameViewport, scale: number): number;  // справочная
export function scaleForEdgeDistance(viewport: FrameViewport, edgeDist: number): number;

export function layerFillAlpha(level: number): number;
export function layerLineAlpha(level: number): number;
// УДАЛЯЕТСЯ: export const TARGET_WIDTH_LY
```

**Формулы (обязательны к переносу в код):**

```text
sectorWidth(n)   = MAX_VISIBLE_WIDTH / LEVEL_STEP ** n          // ед. карты = св.г.
L12              = 10 000 / 1,9194^12 = 3,999577… св.г.        // §16.4 округляет до 4,00
rawLevel         = clamp(floor(ln(10000 / visibleWidth) / ln(LEVEL_STEP) + 1e-9), 0, 12)
                   w ≤ deepestWidth·(1+1e-9) → 12;  w ≥ 10000 → 0
markerDiameter(w)= clamp(2,5 · (10 000 / w)^0,3544, 2,5, 40)
maxScale         = MAX_SCALE = 500  (не зависит от viewport)
visibleWidthLyForLevel(n) = visibleWidthForLevel(n) / UNITS_PER_LY
edgeDistance     = min(w,h) / (2 · scale · UNITS_PER_LY)        // 1,08 св.г. на 1920×1080 на упоре
```

Гистерезис `±12 %` **сохраняется**: вход на уровень `n+1` при `w ≤ visibleWidthForLevel(n+1)·0,88`, выход при `w ≥ visibleWidthForLevel(prev)·1,12`. Асимметрия для последнего уровня сохраняется (`enterThreshold = deepestWidth·(1+1e-9)`), иначе `L12` недостижим. На упоре `1920 · 0,002 = 3,84 св.г. ≤ 3,999577` — уровень остаётся `L12`, `L13` не существует.

`layerFillAlpha` / `layerLineAlpha` — прежние формулы, диапазон `L2…L12` получается сам из `DEEPEST_SECTOR_LEVEL`; второй таблицы уровней не заводить (`И-8`).

## 5. Журнал решений Гайдлайнера (отклонённые варианты остаются здесь)

| № | Вопрос | Решение и причина |
|---|---|---|
| 1 | §12.1 даёт `F-1` 17 файлов, §18.3 — 18 (добавлен `tools/verify_sector_core.mjs`) | **Берём 18 по §18.3.** Гейт ядра проверяет геометрию лестницы и префиксы; оставить его на старой формуле — значит получить зелёный `npm test` при красном стыке модулей. §17.24 тоже включает тул в `Z-5`.
