## 2. Браузерная приёмка (была NOT_CHECKED в раунде 1 — теперь выполнена)

Среда: Chromium из `@sparticuz/chromium` + `playwright-core` (headless,
SwiftShader — программный GL; **замеры кадров/скорости из этой среды не
представляются как производительность пользовательского GPU**), сервер
`vite preview :8080`, гейт `KP-ADM-DEMO-27`. Сценарий: импорт seed-документа
(две штриховые области с контрастными переопределениями цвета) →
последовательность пользовательских действий мышью.

Результат: **12/12 шагов успешно** (десктоп 1440×900 и mobile 390×844):

1. UI-импорт JSON через панель (notice в changes-блоке).
2. Клик выбирает штриховую область («Правится: контур области "Альфа-мазок"»).
3. Двойной клик по линии → 6 якорей.
4. Уточнение сегмента 2+4.
5. Тяга якоря коммитится («Форма применена»).
6. Сочетание пары строит автолинию («линия раздела построена автоматически»).
7. Пиксельная проверка разделения по снимку: красная зона выше автолинии,
   синяя ниже (12 красных / 57 синих точек классификации из 81 пробы).
8. «Править линию» включает инструмент и открывает правку линии пары.
9. Экспорт содержит якоря штриха (10), пару и ручную линию (6 якорей).
10. Реимпорт экспорта → продолжение правки по сохранённым якорям (10 шт.).
11. Mobile: нет горизонтального переполнения (scrollWidth=390).
12. Mobile: выбор области после сворачивания панели штатной кнопкой
    (панель при 390×844 накрывает почти всю канву — см. вопрос 5).

## 7. BLOCKED / ограничения (не PASS)

- **Longest-компонента автолинии** (B4): многосвязная зона правится по самой
  длинной части, остальные делятся авторежимом — сознательное ограничение v1,
  честное сообщение при создании пары. Случай «каждая компонента со своей
  линией» в этой итерации не поддержан (см. вопрос 2).
- **Материализация колец штриховых областей** (B1): деформация записывается в
  точки штриха, `rings` остаются пустыми — данные не дублируются, но владелец
  может предпочесть материализацию кольца при первой правке (вопрос 1).
- **S1 LOD**: гейта масштаба для якорной правки нет; расхождение с видимой
  упрощённой линией в зоне деформации до ~486 ед. при L0 (вопрос 4).
