# ADM-SECTOR-R3-DOCS (Р3): разведка документации

> **ID:** `ADM_SECTOR_R3_DOCS_V1` · **Место:** 3 из 3, отчёт + дословный отчёт Р2 → Р4.
> **Вход:** **только отчёт Р2**. Отчёт Р1 и детали карточек Р1/Р2 тебе не передаются; «без деталей второго» — подробности задания Р2 в отчёт не переносить.
> **База:** `origin/main = 3554e92`; активная ветка сессии с влитым `main`.
> **Адресат:** назначается владельцем при выдаче. Язык — русский.
> **Режим:** read-only. **Правок не вносишь**, даже если противоречие очевидно: занесение изменений — отдельный этап Р4.

## 1. Цель

Найти все расхождения документов с фактом, который зафиксирован в отчёте Р2, и предложить по каждому **минимальную** правку. Различать: устаревшее, противоречие, пропуск, битая ссылка, документ-сирота, лишнее упоминание вырезанного.

Обязательно **программно** проверить гейт документации: `python3 tools/check_docs.py` (лимит 200 строк, один H1, прыжки заголовков, относительные ссылки и якоря, входящие ссылки). Результат записать в отчёт как `доказано`.

## 3. Что должно быть в отчёте

- Таблица `файл:строка | тип расхождения | что не так по отчёту Р2 | минимальная правка | можно ли вносить без решения владельца`.
- Отдельный список «оставить как есть»: исторические записи и архивы, где правка означала бы переписывание истории.
- Список пунктов, которые требуют решения владельца, а не правки.
- Итог `python3 tools/check_docs.py`: `OK` или точный текст ошибки.

## 4. Формат отчёта

До **30 строк**, только текст, метки `доказано / наблюдение / предложение / выбрано`. Начинать с базы, `HEAD` и пометки «вход: отчёт Р2». Не предлагать правки кода, данных, тестов и CI.

## 5. Чего не делать

- Не вносить правки, не создавать файлы отчёта (чтобы не плодить документы-сироты), не запускать полный набор тестов.
- Не переписывать исторические записи и не удалять документы.
- Не передавать Р4 свою карточку или детали Р2 — только свой отчёт и дословный отчёт Р2.

## 6. Проверки и останов

`git status --short`, `git diff --name-only origin/main...HEAD` (пусто), `python3 tools/check_docs.py`, `git diff --check`. Останов: отчёт готов, дерево чистое. **Р4 получает:** твой отчёт + дословно отчёт Р2, без отчёта Р1.
