   `MAX_GRID_LINES = 512`, `MAX_GRID_LABELS = 64` не подняты; при превышении — деградация
   до одного тира.
3. Кодек: `ADDRESS_TIERS` — 8 записей, `addressOf` по-прежнему 5 букв, `173/173` и
   `11/11` golden vectors не изменились; `prefixOf/rectOf/centerOf/parseAddress` работают
   на глубине 6–7 букв по `address.md` §7.6.
4. `npm test` — те же **`8`** известных планетарных падений по именам; девятое блокирует.
5. `git diff --name-only origin/main...HEAD` — **только** 13 файлов из §3.
6. Отчёт по форме исполнения §8 отправлен; ветка запушена, PR открыт, слияния не было.

**Не входит:** поиск по 6–7 буквам (открытый вопрос §16.8, владелец), стрелки (`F-4`),

## 4. Контракт до буквы (`Interface-First`)

### 4.1. `src/atlas/sector-address.ts`

```text
export type AddressLetters = 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7;   // было 0…5
// ADDRESS_TIERS — ровно 8 записей, T0…T5 без изменения чисел:
//   T0 10000, T1 2000, T2 400, T3 80, T4 16, T5 3.2,
//   T6 «Точка» 0.64, T7 «Пята» 0.128 (address.md §7.2)
export function addressOf(x, y): SectorAddress;            // без изменений: prefixOf(…, 5)
export function prefixOf(x, y, letters: AddressLetters);  // guard letters > 5 заменить на > 7
export function rectOf(addr): { x, y, size };             // size = ADDRESS_TIERS[letters.length].cellSize
export function centerOf(addr): { x, y };                  // центр ячейки длины адреса (§7.6)
export function parseAddress(text): SectorAddress | null; // принимает 5, 6 и 7 букв
```

- `parseAddress`: длина `5…7` и `/^[A-Y]{5,7}$/`; пустой ввод, 4 и 8 букв, чужой сектор по-
  прежнему `null`; `isValidFullAddress` синхронно. Для 5 букв поведение побайтово прежнее.
- `rectOf`: убрать зашитый `ADDRESS_TIERS[5]`, размер брать по длине; для 5 букв результат
  обязан остаться `3,2` (тесты «прямоугольники» не меняют ожиданий).
- `formatAddress`, `SECTOR_CODE`, `ALPHABET`, `MAP_SIZE` не трогать; golden vectors `11/11`
  и `173/173` неприкосновенны.

### 4.2. `src/atlas/sector-scene.ts`

```text
// УДАЛЯЕТСЯ: export const GRID_TIER_BY_LEVEL
export const GRID_CELL_MAX_PX = 450;
export const GRID_CELL_MIN_PX = 16;
export interface GridTiers { readonly primary: number; readonly nested: number; }
export function gridTiersFor(scale: number): GridTiers;
//   t = минимальный i ≥ 1, для которого одновременно:
//     ADDRESS_TIERS[i].cellSize * scale <= 450
//     ADDRESS_TIERS[i + 1].cellSize * scale >= 16
//   nested = t + 1, пока t + 1 ≤ 7 и его ячейка ≥ 16 px; иначе сетка из одного тира
export interface SceneGridLine {
  readonly kind: 'grid.line';
  readonly tier: string;            // 'T1'…'T7'
  readonly cellSize: number;
  readonly alpha: number;           // 0.16 старший, 0.07 вложенный
  readonly x1; readonly y1; readonly x2; readonly y2;
}
```

- Константы альф завести в этом модуле (`0,16`/`0,07`), рендерер сам числа не печатает.
- `GRID_FIRST_LEVEL` `1 → 0` (G7.13: сетка на `L0…L12`); `GRID_LAST_LEVEL = 12` без изменений;
  `MAX_GRID_LINES = 512`, `MAX_GRID_LABELS = 64` не поднимать; при превышении — один тир.
- Сигнатура `gridFor(viewport, camera, level)` сохраняется; внутри — два тира через
  `gridTiersFor(frame.w / cam.visibleWidth)`, линии несут `tier` и `alpha`. Подпись —
  `prefixOf(center, primary)` (букв столько, каков индекс старшего тира; `t = T3 → KP·REQ`),
  порог `loupeLabelFits` не ослабляется.
- `loupeGridFor`: база — `gridTiersFor(scale).primary` вместо удалённой таблицы; потолок
  `Math.min(base + LOUPE_MAX_TIER_STEP, 7)`; `LOUPE_*` константы и окно `12×12` без изменений;
  на `L10…L12` лупа больше не возвращает `null`-тир (адресация глубиной 6–7 букв, §7.2).
