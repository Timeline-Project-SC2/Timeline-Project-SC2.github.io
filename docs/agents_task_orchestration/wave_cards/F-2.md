## 1. Цель и проверяемый критерий готовности

Слой фракционных сетей (баблы, узлы, поле контроля, ленты, каналы, всполохи) должен жить на
всей глубине лестницы `L2…L12`, а единственным источником диапазона обязан стать
`layerFillAlpha` из `level-ladder.ts` — собственная таблица уровней в `faction-net.ts`
удаляется (инвариант `И-8`: пороги уровней живут только в лестнице).

**Готово = одновременно:**

1. `NET_LAYER_LEVELS` не существует ни в одном файле репозитория (доказательство — грепом);
   `isNetLayerLevel(level)` реализован буквально как `layerFillAlpha(level) > 0`;
   сигнатура `netsAtLevel` сохранена до символа.
2. Поведение: `isNetLayerLevel` = `true` на каждом `L2…L12`, `false` на `L0`, `L1`,
   `S0…S2` (уровни `13…15`) и на отрицательных; `netsAtLevel` отдаёт сети только внутри
   диапазона.
3. `npm test` — те же **`8`** известных планетарных падений по именам (исполнение §6);
   девятое блокирует карточку. Все гейты зелёные.
4. `git diff --name-only <коммит-карточки>...HEAD` содержит **только** четыре файла из §3.
5. Отчёт по форме исполнения §8 отправлен Гайдлайнеру; ветка запушена, PR открыт,
   **слияния не было**.

**Не входит (запрещено делать в `F-2`):** тиры `T6/T7`, `gridTiersFor`, удаление
`GRID_TIER_BY_LEVEL`, правка `styles.css` и шаблонов, любые новые числа вне §8.1, изменения
геометрии баблов/лент/каналов и данных `data/*`. Пустая сетка на `L5…L12` — вход в `F-3`,
а не дефект `F-2` (решение №12 `F-1`).

## 4. Контракт до буквы (`Interface-First`)

### 4.1. `src/atlas/faction-net.ts`

```text
// НОВЫЙ импорт (рядом с существующими):
import { layerFillAlpha } from './level-ladder.ts';

// УДАЛЯЕТСЯ целиком, вместе с комментарием над объявлением:
export const NET_LAYER_LEVELS: readonly number[] = Object.freeze([2, 3, 4, 5, 6, 7, 8, 9]);

// Единственный источник диапазона — лестница (И-8), без своей таблицы уровней:
export function isNetLayerLevel(level: number): boolean {
  return layerFillAlpha(level) > 0;
}

// Сигнатура и имя сохраняются до символа; тело делегирует isNetLayerLevel:
export function netsAtLevel(
  nets: readonly FactionNet[],
  level: number,
): readonly FactionNet[];
```

Поведение гарантируется формулой лестницы (`level < 2 || level > 12 → 0`): `true` на
`L2…L12`, `false` на `L0`, `L1`, `13`, `14`, `15` и отрицательных. Использовать
именно `layerFillAlpha`, а не `layerLineAlpha` — так записано в §18.4, хотя диапазоны
совпадают.

**Комментарии модуля (все пять устаревших мест — перечислены, новые не искать):**

1. Шапка файла, пункт 7: «Слой живёт на уровнях территорий `L2…L9`
   (`NET_LAYER_LEVELS`…)» → диапазон `L2…L12`, источник — `layerFillAlpha`/
   `layerLineAlpha` из `level-ladder.ts`; упоминание `NET_LAYER_LEVELS` убрать.
2. Блок-комментарий над удаляемой константой (`L2…L9`, `TERRITORY_LEVELS`, `Z-4b`) —
   заменить коротким комментарием о том, что диапазон выводится из лестницы.
3. JSDoc `isNetLayerLevel`: «(`L2…L9`)» → «(`L2…L12`)».
4. JSDoc `netsAtLevel`: «вне `L2…L9`» → «вне `L2…L12`».
5. Ссылка на §8.1 в комментариях сохраняется — это SSoT диапазона.
