## 4. Допуски и технические решения (не утверждённые владельцем)

- **Береговое правило** уточнения: клик не двигается; более длинный берег сегмента
  делится на 3 равные дуги, короткий — на 2; при равенстве 3 части получает левый.
  Части внутри берега равны точно (по дуге), между берегами равенства нет — так
  якорь остаётся ровно под курсором.
- **Равноудалённая автолиния** = геометрическое место `distA = distB`, где расстояния —
  до ближайшей точки вне заливки каждой области (сетка 160 ячеек, веса 1/√2,
  погрешность до ~8 %, допуск проверки 18 %). Это середина по «глубине» заливок,
  не по хорде и не по центрам.
- **Концы линии пары** удерживаются рамкой зоны пересечения (габариты зоны);
  выход стягивается к границе с уведомлением.
- **Запрет пересечения** = отклонение действия с сообщением (не остановка у границы
  и не предупреждение постфактум): данные не портятся, выбор показан владельцу
  как решение исполнителя.
- **Мягкий переход** = 4 ходка обводки вдоль линии под клипом выреза с линейным
  спадом альфы (ступенчатое приближение градиента; резкий режим — по умолчанию).
- **Многосвязная зона** правится по самой длинной части; остальные без линии (v1).

## 7. Вопросы владельцу (единый список)

1. **Береговое правило** уточнения (клик не двигается; длинный берег 3 части,
   короткий 2) — принять или предпочесть строго равные 5 частей с микросдвигом
   клика?
2. **Метрика автолинии**: равные заглубления заливок (реализовано) или другая
   «равноудалённость» (по центрам, по хорде)?
3. **Мягкий переход**: достаточно ступенчатого приближения (4 ходка) или нужен
   точный градиент по расстоянию (дороже в отрисовке)?
4. **Запрет пересечения**: подтверждить механику «отклонение действия с сообщением»
   против «остановка у границы».
5. **Концы линии пары**: достаточно рамки зоны пересечения как «зоны взаимодействия»?
6. **Многосвязная зона**: достаточно правки самой длинной части (остальные —
   в авторежиме без линии)?
7. **Браузерная приёмка**: где и кто выполняет (нужен браузер со сценарием §11);
   в среде разработки загрузка браузера заблокирована сетью.
