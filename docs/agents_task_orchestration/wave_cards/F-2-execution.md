## 6. Гейты и доказательства

**База, снятая Гайдлайнером 26.10.2026 на `2adfb12` (Node 22 в песочнице при `.nvmrc` =
24; ограничений `engines` в `package.json` нет, все гейты зелёные — решение F2-6):**

| Проверка | База |
|---|---|
| `npm test` | `411` тестов, `403 pass`, **`8 fail`** — Stage-8.5, Stage-8.10b ×2, A-17 ×2, W26b ×2, контракт ядра Stage-8.10b |
| `faction-net` + `net-channels` отдельно | `62` теста, `0` падений |
| `verify:docs` | OK, `211` файлов |
| `typecheck` / `build` | зелёные |
| `verify:sector-core` / `verify:address` / `verify:no-raster` / `verify:publish` | зелёные |

**Обязательные команды перед финишем** (перед ними `npm ci` — в песочнице `node_modules`
может отсутствовать):

```bash
npm ci
npm test                      # сравнение с базой по ИМЕНАМ падений, не по счётчику
node tools/verify_sector_core.mjs --verbose
node tools/verify_sector_address.mjs
node tools/verify_no_raster.mjs
npx tsc --noEmit
npx eslint site src
npm run build
npm run verify:publish
npm run check:planet-core     # в CI не выполняется (решение №14 F-1) — гонять локально
git diff --check
git diff --name-only origin/main...HEAD
grep -rn "NET_LAYER_LEVELS" src tests site tools   # обязан молчать
```

- **`G7.4` (бюджет кадра на `L8…L12`):** в песочнице нет WebGL2, GPU p95 не измеряется —
  в отчёте честно отметить как непроверенное, цифры не выдумывать. Доказательная часть
  карточки: геометрия и бюджеты (`MAX_CHANNELS_PER_FRAME`, `MAX_GRID_CELLS`,
  `MAX_FLARES_PER_NET`) не менялись, новых аллокаций в кадровом пути нет; визуально-
  перформансная приёмка `L8…L12` — в `F-6` у владельца.
- **`G7.13` (сетка поверх заливки читается):** полный гейт закрывает `F-3` (два тира,
  подписи с контуром). Срез `F-2`: заливка и контур реально живут до `L12` (ассерты
  §4.3–4.4 карточки), альфа не падает ниже полов `0,25`/`0,45` (тесты `T1`/`T2`),
  порядок слоёв в рендерере не изменён.
- CI-джоба «Скрипты сайта» красная на всех PR из-за тех же восьми падений: шаги после
  `npm test` в `check.yml` не выполняются — `lint` и `check:planet-core` обязательны
  локально (решение №14 `F-1`).
- **Норма падений `npm test` — те же `8` планетарных.** Девятое падение блокирует
  карточку; чинить разрешено только файлы из своего `OWNED_FILES`.

## 7. Риски (векторы отказа, `rc-08`)

| № | Вектор отказа | Что делаем заранее |
|---|---|---|
| 1 | Удаление константы молча ломает `net-channels.test.mjs` — его не было в матрице §18.3 | Решение F2-1: файл включён в `OWNED_FILES` до старта; правка ограничена двумя строками |
| 2 | Тест `T4` закрепляет старое поведение (`isNetLayerLevel(10) === false`) молча | Переписывается целиком по §4.3; старый диапазон `[2…9]` не остаётся ни в одном ассерте |
| 3 | Воркер «заодно» чинит сетку: `GRID_TIER_BY_LEVEL`, `styles.css`, `T6/T7` | Прямо запрещено §1 карточки; пустая сетка `L5…L12` — ожидаемый вход в `F-3` (решение №12 `F-1`) |
| 4 | Тяга подкрутить альфу/числа под глубину — новые числа вне §8.1 | Диапазон уже выводится лестницей; любая новая константа — эскалация, не решение на месте |
| 5 | Рендерер перестанет матчить regex-тест `net-channels` после правки комментариев | Сохранить буквальный `isNetLayerLevel(level)`; прогон `net-channels` на шаге 3 |
| 6 | Девятое падение `npm test` из-за планетарного дрейфа или побочной правки | Норма — те же 8 по именам; новое падение блокирует карточку, чинить только в своём файле |
| 7 | GPU-замеры бюджета выдаются за сделанные без WebGL2 | Честная отметка «не проверено», как в приёмке `F-1`; приёмка `G7.4` глазами — `F-6` |

## 9. Эскалация и стоп

- Любое противоречие контракта §4 карточки коду или данным — **стоп и вопрос**, не догадка.
- Третья неудачная попытка — эскалация владельцу по §18.6
  [`../waves/f-gates.md`](../waves/f-gates.md): что пробовали, что красное, спорный файл.
- **Стоп перед merge:** слияние `F-2` координирует владелец с Гайдлайнером; до зелёных
  гейтов §6 и вердикта `rc-04` карточка `F-3` не выдаётся.
- Сдвиг сроков «молча» запрещён: оформляется строкой в журнале решений этой карточки.

## 10. Журнал решений Гайдлайнера (отклонённые варианты остаются здесь)

| № | Вопрос | Решение и причина |
|---|---|---|
| F2-1 | Матрица §18.3 даёт `F-2` три файла, но `tests/net-channels.test.mjs` импортирует `NET_LAYER_LEVELS` (строки 31, 658) и упадёт после удаления константы | **Файл включён в `OWNED_FILES` `F-2` (4 файла), матрица §18.3 правится Гайдлайнером тем же docs-PR.** Аналог решения №1 `F-1`: расхождение матрицы и кода снимается до старта воркера. Вариант «оставить устаревший ре-экспорт» отклонён: против §18.4 («удаляется») и инварианта `И-8`. |
| F2-2 | Какой функцией лестницы задавать диапазон | **Строго `layerFillAlpha(level) > 0`, как в §18.4.** С `layerLineAlpha` диапазон совпадает, но буква контракта названа первой; второй источник диапазона не заводим. |
| F2-3 | Объём правок `canvas-renderer.ts` | **Только комментарий `L2…L9 → L2…L12`.** Гейты `drawNetLayer`/`drawNetChannels`/`drawNetFlares` уже делегируют лестнице и автоматически открывают `L10…L12`; структурные правки создали бы риск regex-теста и лишний diff. |
| F2-4 | Переписывать ли альфа-тесты `T1`/`T2` | **Нет.** В #305 они уже приведены к лестнице `L12` (таблица `FILL_ALPHA_BY_LEVEL`). Переписывается только устаревший `T4`; `T3` расширяется циклом до `level < 12` — формула держит ассерт без ослабления. |
| F2-5 | Гейты `G7.4`/`G7.13` без WebGL2 | Закрываем доказуемый срез (диапазон, альфа-полы, отсутствие новых чисел и аллокаций, порядок слоёв); GPU и визуальная читаемость сетки поверх заливки честно переносятся в `F-6`, полный `G7.13` — за `F-3`. Цифры производительности не выдумывать. |
| F2-6 | Среда исполнения: `.nvmrc` требует Node 24, в песочнице Node 22 | Ограничений `engines` в `package.json` нет; база снята на Node 22, все гейты зелёные. Воркер фиксирует версию в отчёте; блокирующим расхождение не считается. |
