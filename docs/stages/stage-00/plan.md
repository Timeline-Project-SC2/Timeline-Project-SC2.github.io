## Цель

Зафиксировать входные данные и условия: репозиторий, источник карты, стабильные пути к файлам, разрешение на использование, систему координат. Создать сайт и включить GitHub Pages.

## Входит

* собственный репозиторий и публикация через GitHub Actions;
* шаблоны `data/sources.json` и `data/meta.json`;
* черновой `.github/workflows/sync.yml`;
* решение о преобразовании координат (`transform`).

## Не входит

* парсер CSV, синхронизация и валидация — Этап 2 / «Этап A»;
* сборка тайлов и WebP — отдельный контур `tools/build_assets.py`;
* юридическая экспертиза лицензии — вне кода.

## Артефакты

* [`data/sources.json`](../../../data/sources.json) — реестр источников;
* [`data/meta.json`](../../../data/meta.json) — версия и размеры;
* [`.github/workflows/sync.yml`](../../../.github/workflows/sync.yml) — черновик.

## Гейт и приёмка

Формального гейта нет. Критерий готовности — ответы владельца по источнику, путям и координатам. Фактически вопросы закрывались по ходу Этапов 1–2, когда источником стала опубликованная книга Google Sheets.
