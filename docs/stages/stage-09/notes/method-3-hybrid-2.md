#### 2.3.5. Сводная таблица сравнения

| Критерий | Метод 1 (гамма) | Метод 2 (уникальные тайлы) | Метод 3 (гибрид) |
|---|---|---|---|
| Передача морфологии `tundra ↔ rainforest` | **нет** | есть | есть |
| Отделение биомассы от грунта | нет | частично (альфа) | **да** (`FoliageMask`) |
| Реакция на `riverInfluence` / `slope` / `volcanism` | нет | нет (запечено) | **да** (per-pixel) |
| Ghosting на границе биомов | нет (нечего смешивать) | **сильный** (`Var ×0.5`) | нет (`heightBlend`) |
| Тайлинг | заметен на близких | заметен, но реже | подавлен (hex + macro) |
| Публикация (`.publish/`) | `≈ 0,5 МБ` (1 тайл) | `18…72 МБ` | **`≈ 15,9 МБ`** (12 архетипов, 2 LOD) |
| Видеопамять (резидентно) | `5,3 МиБ` | `256…1024 МиБ` | **`32…64 МиБ`** |
| Сеть на первую пару биомов | `0,1 МБ` | `2,2…17,9 МБ` | **`2,6 МБ`** |
| Стоимость фрагмента | `1 fetch` | `2 fetch` (+нормали) | `12…15 fetch` (hex), `4…6` (low-end) |
| Реакция на `prefers-reduced-motion`/слабый GPU | — | — | деградация до 2 тапов |
| Сложность CI | нет | высокая (64 источника) | средняя (12 источников) |
