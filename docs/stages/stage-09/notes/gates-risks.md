## 5. План внедрения (Zero File Overlap) и гейты

### 5.1. Потоки

1. **Воркер 1 — данные климата/биомов в воркере.** `local-map-worker.ts`
   (карты `biome*`/`climate*`, `meta.biomeTopKeys`), `local-map-contract.ts`
   (версия `local-map-wire-v2`, `localAtlasVersion` в `patch_key`),
   `tests/local-map-stage9.test.mjs`.
2. **Воркер 2 — текстуры и шейдер.** `local-map-shaders.ts` (hex-tiling,
   `heightBlend`, `tint`, `trample`), `local-map-renderer.ts` (текстурные
   массивы `TEXTURE_2D_ARRAY`, юниты `2…5`, `EXT_texture_filter_anisotropic`
   при наличии, деградация по `MAX_TEXTURE_IMAGE_UNITS`), загрузка
   `assets/veg-atlas.json` с ленивой подгрузкой по биомам.
3. **Воркер 3 — ассеты и CI.** `tools/build_assets.py`, `.gitignore`,
   `.github/workflows/pages.yml`, `tools/verify_veg_atlas.mjs`.
4. **Воркер 4 — бенчмарк и документация.** `tools/bench_local_map_stage9.mjs`
   (бюджет кадра, время загрузки текстур), `docs/stages/stage-9-vegetation-atlas.md`
   (этот файл), `CHANGELOG.md`, `HANDOFF.md`.

### 5.2. Гейты (продолжение G4 → G5)

| Гейт | Критерий |
|---|---|
| **G5.1** | первая загрузка текстур растительности на участок `≤ 3 МБ` (2 биома × 2 LOD) |
| **G5.2** | видеопамять текстур `≤ 64 МиБ` (десктоп), `≤ 40 МиБ` (low-end профиль) |
| **G5.3** | steady-кадр: `p95 ≤ 20 мс` десктоп / `≤ 33,3 мс` Redmi Note 10, `0` кадров `> 100 мс` |
| **G5.4** | `genMs` воркера не вырос более чем на `15 %` относительно `27,4 мс` (`v=64`) / `26,5 мс` (`v=128`) |
| **G5.5** | шов тайла `≤ 2,5 / 255 RMS` на всех 12 архетипах (CI-проверка) |
| **G5.6** | визуально: граница `tundra ↔ boreal` и `grassland ↔ shrubland` читается по **силуэту**, а не только по цвету |

### 5.3. Порядок первых двух шагов

1. `image_version()` → `rglob` и `.gitignore` + `pages.yml` (**до** первого
   коммита новых ассетов, иначе кэш браузера и кэш CI разъедутся).
2. `build_vegetation()` с `--check` и манифестом — на одном архетипе (`T1a`),
   чтобы провалидировать весь конвейер без 12 источников.

## 6. Риски и открытые решения

| ID | Вопрос | Рекомендация | Когда |
|---|---|---|---|
| T9-1 | `1024²` на все архетипы или `512²` для травяных? | `1024²` в «ближнем» наборе, `512²` в базовом; травы (`T1/T2/T3/T4`) допустимы `512²` и в ближнем | при арт-приёмке |
| T9-2 | Hex-tiling на мобильных | `2 tap` dual-scale по умолчанию, `3 tap` hex — при `devicePixelRatio ≤ 2` и `MAX_TEXTURE_IMAGE_UNITS ≥ 16` | до мерджа |
| T9-3 | Третий тайл для дельт | ленивая подгрузка `T4` только при `deltaWeight > 0,05` | Этап 9, вторая очередь |
| T9-4 | Канон `T7 (Xeno)` для Бель'Шира / Зеруса / Шакураса | отдельная палитра-пресеты в `veg-config.json`; базовый архетип `T6`, `T7` — оверлей | нужен ответ владельца |
| T9-5 | Снег/лёд (`sea_ice`, `polar_ice`, `alpine`) | отдельные грунтовые архетипы, не растительные | Этап 9, вторая очередь |
| T9-6 | Дельты и озёра: кто рисует воду | вода остаётся в `TERRAIN_FRAGMENT_SHADER` (`z ≤ 0`), растительность её не перекрывает (`cov` обнуляется у зеркала) | реализовано в §3.8 |
