## Решения этапа

**D8-1 · Активный центральный гекс + 10-кольцевая сферическая юбка + непрозрачный купол неба.** 7-лепестковый кластер отклонён.
**D8-2 · Фиксированный физический радиус гекса** `LOCAL_PATCH_BASE_RADIUS_M = 2500 м`; селектор «Видимая ширина» меняет только камеру, без перегенерации.
**D8-3 · 11-ступенчатая логарифмическая шкала** `1.2 … 1250 км`, наклон `0.31 … 0.78` рад, анимация 550 мс.
**D8-4 · Межъячеечная синхронизация** через единый `planetSeed`; знаковая батиметрия; сквозные реки; 5 высотных поясов; `LOCAL_REST_YAW = -π/2` — камера строго на Север.
**D8-5 · Квик-навигация:** кольца 1–5 (91 ячейка с центром), `rebaseLocalCameraState`, отдельный слой `#localMapQuickNav`.
**D8-6 · Каскад детализации A-14/A-15:** точная зона в радиусе 5 гексов, гибрид «совпадение + пре-рендер», при нехватке скорости ограничивать камеру.
**D8-7 · Инженерные решения аудита:** A-1 (одна generation), A-3 (ленивое Wasm), A-12a (упаковка вне главного потока), A-10 (FULL EQ), A-13 (профилирование).
**D8-8 · A-18 — план, не срочный рефакторинг:** `planet-globe.ts` 3 477 строк, но распил посреди отладки запрещён.
