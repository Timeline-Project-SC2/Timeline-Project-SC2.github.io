# Горизонт Stage-8.1…8.3: юбка, купол, панорама

Сводный архитектурный отчёт итераций **Stage-8.1 … Stage-8.7** (`PR #169`,
`#171–#200`, `#202–#204`) для 3D-экрана локальной карты на маршруте `/planet-globe/` поверх
базовой волны Этапа 8 ([`stage-8-local-map.md`](../../stage-8-local-map.md)):

- **Stage-8.1 и Stage-8.2 / 8.2.1 (раздел 0, `PR #169`, `#171`, `#176–#180`):**
  переход от первой 6-кольцевой юбки и отклонённого 7-лепесткового кластера
  (`PR #172–#175`) к обрезке меша $257 \times 257$ строго по одному активному
  гексу в окружении непрерывной сферической юбки с двухфазным спуском камеры;
- **Stage-8.3 (разделы 1–4, `PR #181–#183`):** подключение непрозрачного купола
  неба в рендер-цикле, дневная горная дымка и панорамный ракурс камеры изнутри
  долины на горный горизонт;
- **Stage-8.4 (раздел 5, `PR #184–#186`):** расширение прогрузки местности до
  10 колец гексов (`145 × 85`), сдвиг старта тумана за первые 3–4 круга и
  плавное скольжение камеры от гекса к гексу;
- **Stage-8.5, 8.5.1 и 8.5.2 (раздел 6, `PR #187–#191`):** фиксированный
  физический масштаб гекса (`LOCAL_PATCH_BASE_RADIUS_M = 2500 м`),
  11-ступенчатая логарифмическая шкала «Видимой ширины» (`1.2 … 1250 км`) и
  хотфиксы переходов по соседям и кромки прибоя;
- **Stage-8.6 (раздел 7, `PR #192–#194`):** межъячеечная синхронизация
  `planetSeed`, знаковая батиметрия (`z < 0`), сквозные реки на любой высоте
  (`terraformMap = 0`), 5 метрических гипсометрических поясов, объёмный шейдинг
  воды и ориентация камеры строго по Северу (`LOCAL_REST_YAW = -Math.PI / 2`);
- **Stage-8.7 и интеграционные фиксы 8.7.1 / 8.7.2 (раздел 8, `PR #198–#200`, `#202–#204`):**
  кольцевые LOD-области `1–5` (`6/12/18/24/30` ячеек, `RING_HF_RES = [256, 64, 32, 16, 8, 4]`),
  атомарный ре-бейзинг камеры `rebaseLocalCameraState` без перелётов между гексами
  и голографические квик-стрелки на гранях активного гекса.

## 0. Stage-8.1 и Stage-8.2 / 8.2.1 · От экспериментального 7-гексового кластера к выделенному центральному гексу и непрерывному горизонту

1. **Первая сферическая юбка Stage-8.1 (`PR #169`, `#171`) и отклонённый 7-лепестковый эксперимент (`PR #172–#175`):**
   - в `Stage-8.1` (`PR #169` `5d0e0ce` и хотфикс бесшовной сшивки высот `PR #171`
     `334b4c1`) вокруг квадратного участка впервые были построены сферическая юбка
     из 6 колец гексов с планетарным проседанием кривизны, оптическим размытием
     дальних планов и атмосферным куполом;
   - следом в серии `PR #172–#175` (`b539c0b`, `bd40048`, `f49ef83`, `363aa9b`,
     экспериментальная ветка `Stage-8 Hybrid A+B`) проверялся альтернативный
     7-лепестковый сегментированный кластер `Patch7` с 3D-фасками граней
     (`bevelDropM`) и прозрачным фоном над живым 3D-глобусом. На визуальной
     проверке этот вариант был **отклонён владельцем**: ступенчатые фаски и
     висящий в воздухе «остров» из 7 сот разрушали целостность планетарного
     ландшафта.
2. **Утверждение целевой архитектуры в волне Stage-8.2 (`PR #176`, `#178`, `#179`, `#177`) и хотфиксе Stage-8.2.1 (`PR #180`):**
   - регулярный квадратный меш центрального участка $257 \times 257$ обрезается
     во фрагментном шейдере строго по контуру одного активного гекса
     (`centerHexDist = hexMetric2D(v_worldPos.yx) <= hexApothem`, где
     `hexApothem = 0.8054 * focusRadiusM`), подсвеченного тонким тактическим
     ободком без 3D-фасок;
   - непосредственно от кромки центрального гекса расстилается единая
     непрерывная сферическая юбка горизонта с гексагональной сшивкой воротника
     (`clusterHexMetric`) и каскадным ослаблением микродеталей рельефа и
     нормалей по мере приближения к горизонту;
   - прозрачность фона отключена в пользу непрозрачного скайдома
     (`opaqueSkyDome`), а погружение с глобуса переведено на плавный двухфазный
     спуск камеры (`flyToDirection` на глобусе + `startLocalDiveInAnim`
     длительностью `1150 мс` по `easeInOutCubic` внутри локальной сцены);
   - хотфикс **Stage-8.2.1** (`PR #180` `ace0c74`) закрепил удержание
     горизонтального зеркала континентальных озёр выше `seaLevel` на юбке
     горизонта и строгий запрет спавна построек на водной глади озёр.

## 1. Купол неба в кадровом цикле (`renderLocalMapFrame`)

`LocalMapRenderer.renderFrame` рисует купол неба (`SKY_DOME_*`) **только** при
наличии `renderOptions.camera`. Прежний вызов камеру не передавал, поэтому
атмосферный лимб и облачный купол отсутствовали на каждом кадре. Волна
Stage-8.3 закрывает это:

- в `renderOptions` передаётся объект камеры, собранный из текущего состояния
  орбитальной камеры локальной карты:
  `camera: { pitch, yaw, fovY: LOCAL_MAP_FOV, aspect, heightM: Math.max(2, eye[2] - target[2]) }`,
  где `aspect = width / height` канваса, а `heightM` — высота глаза над точкой прицела;
- `skyAlpha: 1.0` и `opaqueSkyDome: true` фиксируют непрозрачный купол (рельеф
  сшивается со скайдомом без альфа-смешивания);
- очистка экрана переведена с космической черноты на светлый дневной сизый тон
  `gl.clearColor(0.52, 0.62, 0.74, 1)`, чтобы за сценой не просвечивал уменьшенный глобус;
- палитра атмосферы стала светлой дневной горной дымкой:
  `LOCAL_HORIZON_COLOR = [0.76, 0.82, 0.88]`, `LOCAL_SKIRT_FOG_COLOR = [0.66, 0.74, 0.82]`;
- солнечный свет и ambient выровнены между `renderFrame` и `drawLocalMapFallback`:
  `lightDir = [0.52, -0.38, 0.76]`, `ambientColor = [0.42, 0.45, 0.48]` — рельефная
  светотень гор и долины читается объёмно;
- туман раздвинут, чтобы горные хребты юбки не «съедались» дымкой:
  `fogStart = skirt ? skirt.outerRadiusM * 0.58 : localMapRadiusM * 0.85`,
  `fogEnd = skirt ? skirt.outerRadiusM * 0.98 : localMapRadiusM`
  (в Stage-8.4 коэффициент старта тумана поднят с `0.58` до `0.64` — см. §5.1).

## 2. Панорамный ракурс «изнутри долины на горы»

| Параметр | Было (Stage-8.2) | Стало (Stage-8.3) |
|---|---|---|
| `LOCAL_REST_PITCH` | `0.44` (~25.2°) | `0.31` (~17.8°) |
| Рабочая дистанция `localCameraDistance` | `radiusM * 0.72 / (tan(fov/2) * fit)` | `max(2, radiusM * 0.44 / (tan(fov/2) * fit))` |
| Точка прицела `localCameraTarget` | `[0, 0, centerZ + 12]` | сдвиг вперёд `radiusM * 0.14` по взгляду + `max(14, radiusM * 0.025)` по высоте |
| Старт спуска `startLocalDiveInAnim` | `fromDist = 4.8x`, `fromPitch = 1.30`, `fromTarget.z += radiusM * 0.18` | `fromDist = 5.2x`, `fromPitch = 1.32`, `fromTarget.z += radiusM * 0.25` |
| Нижний предел наклона в `pointermove` (orbit) | `0.12` рад (~6.9°) | `0.06` рад (~3.4°) |

Итог композиции кадра: верхние **28–35 %** занимают горные вершины юбки и
облачный купол неба с атмосферным лимбом, нижние **65–72 %** — зелёная долина
активного гекса с домиками на переднем плане. Взгляд идёт вдоль долины к горному
массиву: точка прицела вынесена вперёд по направлению взгляда и поднята над
центром heightfield, поэтому горизонт остаётся в верхней трети кадра даже после
ручного вращения.

Спуск (фаза 2 двухфазного Dive-in, `LOCAL_DIVE_ANIM_MS = 1150` мс) начинается с
высокой орбитальной точки (`fromDist = 5.2 × targetDist`, `fromPitch = 1.32` рад)
и по кривой `easeInOutCubic` мягко опускает камеру до панорамного уровня долины
(`toDist = targetDist`, `toPitch = LOCAL_REST_PITCH`, `toTarget = target`).

## 3. Планетарное масштабирование горного горизонта

Масштаб сцены задаётся парой `localMapRadiusM` (радиус активного участка) и
`HorizonSkirtData` (6 колец гексов до `outerRadiusM`, сферическое проседание
`planetCurvatureDropM`; начиная со Stage-8.4 — до 10 колец, см. §5).
Перечисленные константы ракурса выражены в долях
`localMapRadiusM`, поэтому при переключении ступеней `1.2 … 1250 км` камера
остаётся внутри долины одного и того же визуального размера, а горная гряда
уходит за сферический горизонт: передний план (домики, гекс) читается в метрах,
дальний план — в сотнях километров скруглённой юбки.

## 4. Проверки волны

```bash
npm run typecheck        # tsc --noEmit
npm run lint             # eslint site src
npm test                 # node --test (включая local-map-stage8.test.mjs)
npm run build            # tsc --noEmit + Vite -> .publish/
npm run verify:publish   # 7 маршрутов, build-manifest.json, паритет экспортов
git diff --check
```

На визуальную приёмку владельца остаются: доля кадра под горы и небо на реальных
разрешениях, читаемость облачного купола в зените и отсутствие «плавания»
горизонта при ручном наклоне камеры.
