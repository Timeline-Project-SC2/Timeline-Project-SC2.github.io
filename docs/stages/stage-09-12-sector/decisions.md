## Решения этапа

**D-20 · `1` единица карты = `1` св.г.; предел `0,002` св.г./px (`MAX_SCALE = 500`),** не зависит от экрана; `edgeDistance` справочная.
**D-21 · Маркер `2,5…40 px`, показатель `MARKER_EXPONENT = 0,3544`;** концы ряда сохранены, средние уровни мельче.
**D-22 · Канон адреса — 5 букв;** `T6 = 0,64`, `T7 = 0,128` используются только в подписи ячейки сетки и лупе; в поиск до отдельного решения не вводить.
**D-23 · Фактическая сетка на всех глубинах:** старший тир `t` + ровно один вложенный `t+1`, ячейка `≤450 px`, вложенная `≥16 px`, толщина `1 px`, альфа `0,16`/`0,07`, подпись в углу.
**D-05 · 13 секторных `L0…L12` + системные `S0…S2` с номерами `13…15`.**
**D-01 · Адрес производный, в CSV не хранится.**
**D-07 · Растр удаляется сразу,** без эталона и `?raster=1`.
**D-13 · `Shift+клик` — карточка точки;** `?coords=1` сохраняет старое копирование.
**D-16 · Полёт — не более 3 промежуточных кадров;** цель `≤2`, `prefers-reduced-motion` → кроссфейд `120` мс.
**D-17 · Стрелки — по расстоянию до центра камеры, не по видимости;** до 5, `|Δθ| ≥ 24°`, `+n`.
**D-18 · Отъезд `×25` (два тира адреса)** с клампом `16 000 св.г.`; `×4` — режим `?recede=levels`.
**Решения F-1 (26.10.2026):** №11 `L11 = 31,8` по формуле; №12 пустая сетка `L5…L12` — вход в `F-3`; №13 `492 514 %` — артефакт readout, в `F-6`; №14 `check:planet-core`/`lint` в CI — отдельная микрозадача по `check.yml`.
