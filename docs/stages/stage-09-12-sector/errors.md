## Ошибки этапа

**E-S1 · Числа ранних редакций не совпадали с данными.** `186` систем вместо `173`, несуществующий `R = 1 200`, «`1 000` единиц = `1` св.г.», `L0…L9` с шагом `10×`. Пересчитано по `data/systems.csv`; версия 4.0 отменила прежние числа.
**E-S2 · Растровая пирамида до `L9` невозможна.** `3,69 млн` тайлов (`≈166 ГБ`), до `1 000 px/св.г.` — `381 млн` (`≈17 ТБ`); на глубине растр кратно размыт. Решение — удалить растр сразу.
**E-S3 · Противоречие масштаба «0,95 против 5 319,5».** Две разные единицы в одной формуле; закрыто решением `D-20` (`1` единица = `1` св.г.).
**E-S4 · Округление `L11`.** Формула даёт `31,75648 → 31,8 px`, таблицы содержали `31,7`. Решено следовать формуле, допуск ужесточён с `0,06` до `0,05`; вариант «оставить 31,7» отклонён.
**E-S5 · Тир сетки был захардкожен** `GRID_TIER_BY_LEVEL = [null,1,1,2…]`. Заменяется `gridTiersFor(scale)`; промежуточное состояние — пустая сетка на `L5…L12`.
**E-S6 · Тип `AddressLetters = 0…5` не вмещал `T6/T7`.** Расширен до `0…7`, но канон адреса остаётся пятибуквенным; `parseAddress` принимает 5–7.
**E-S7 · `NET_LAYER_LEVELS` дублировал лестницу.** Заменён на `isNetLayerLevel(level) = layerFillAlpha(level) > 0`.
**E-S8 · Долг документации 3.x.** Часть разделов описывала старую лестницу; версия 4.0 переписала §6, §7.2, §11, §12.1, §16, §17 и закрыла долг.
