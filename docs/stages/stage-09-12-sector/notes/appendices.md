## Приложение B. Глоссарий

| Термин | Значение |
|---|---|
| **Кадр (frame)** | система координат и метрика отрисовки: `S` — св.г., `O` — а.е., `P` — км |
| **Уровень (level)** | ступень глубины `L0…L9`, `S0…S2`; переключатель контента, не шаг зума |
| **Видимая ширина** | первичная величина камеры в св.г. (или а.е.); `px/св.г.` — производная |
| **Адрес** | `KP·REQHC` — цепочка тиров `5 × 5`, буквы `A…Y` |
| **Тир** | ступень адреса: `T0 сектор … T5 узел`, затем `/тело` |
| **Узел** | ячейка `3,2 св.г.`, звёздное окружение |
| **Апертура** | кольцо-превью системы на `L8…L9` с входом в кадр `O` |
| **Мост** | анимация смены кадра `S → O` |
| **Мёртвая зона** | диапазон масштаба без визуального контента (`≈ 20` удвоений) |
| **Полка ожидания** | пустые слоты тел в системном кадре при отсутствии данных |
| **Карточка точки** | результат `Shift+клик`/долгого нажатия: адрес, `x`,`y`, ближайшая система и расстояние (§7.8) |
| **Полёт** | программное движение камеры: клик-полёт (§6.4) или переход со стрелки (§6.6); `≤ 1 500 мс` |
| **Прицел полёта** | рамка-захват и вложенные кадры в духе `focus-fx` галактики, без паузы `focusZoomDelay` |
| **Стрелка** | шеврон на краю свободной области, указывающий на ближайшую к центру камеры систему по углу `atan2`; интерактивен, подпись видна всегда |
| **Счётчик `+n`** | число объектов, отсечённых лимитом в `5` стрелок или угловым разносом `24°` |
| **Внутренняя стрелка** | стрелка на цель, которая уже видна в кадре: указывает «внутрь» с непрозрачностью `0,6` |
| **`formatDistanceLy`** | единственный форматтер расстояний: `90,8 св.г.`, `1 303 св.г.`, `≥ 10 000 св.г.`; точка как разделитель запрещена |
| **Откат на 2 тира** | фаза `recede`: `×25` по видимой ширине, кламп `16 000 св.г.` |
| **Математическое поле** | канон мира: `10 000 × 10 000` координат без растровой подложки и без ориентира |
| **Единица карты** | `1` координатная единица = `1` световой год (`UNITS_PER_LY = 1`, версия 4.0) |
| **Предел приближения** | `0,002` св.г. на CSS-пиксель, `500 px/св.г.` на любом экране (`TARGET_LY_PER_PX`) |
| **Фактическая сетка** | сетка по границам ячеек `ADDRESS_TIERS`: старший тир `t` + один вложенный `t+1`, одна толщина `1 px` |
| **Старший тир `t`** | самый крупный тир, у которого ячейка на экране `≤ 450 px`, а вложенная `≥ 16 px` |
| **Тир `T6` / `T7`** | `0,64` и `0,128 св.г.` — младшие тиры версии 4.0; видны только на `L11–L12` |
| **Кламп полёта** | при `Δ = 10…12` длительность равна `1 500 мс` — предел, а не формула |

## Приложение C. Чек-лист приёмки владельцем

1. Поле сектора на `L0`, `L4`, `L12` читаемо; стиль принят; картинка-эталон не требуется.
2. Положение систем совпадает с прежним (`x`,`y` не менялись): 8 столиц на своих местах;
   на упоре (`4,00 св.г.` по ширине) видна одна система и её узел, соседей нет — это норма.
3. Маркеры: размер растёт плавно с глубиной (`2,5 → 40 px`), на `L0` точки не сливаются,
   на `L12` апертура не закрывает кольцо орбит; на `L4` маркер `6,3 px` читается.
4. Телефон в портрете: «вся карта по ширине», отъезд до `16 000 св.г.` работает, пинч не залипает.
5. Адреса столиц совпадают с §7.5; адрес копируется и вставляется в поиск.
6. `Shift+клик`: открывается карточка точки; адрес, `x`,`y`, ближайшая система и расстояние
   верны; копирование `x<TAB>y` вставляет пару в две соседние ячейки таблицы.
7. `?coords=1`: `Shift+клик` сразу копирует `x<TAB>y`, карточки нет.
8. Лестница: зум от «вся карта» до `L12` без рывков и миганий; индикатор уровня честный;
   в кадре ровно два тира фактической сетки — старший ярче, вложенный тише, декоративного
   фона `80 px` нет; панорамирование не «скользит» линиями относительно узлов.
9. Вход в систему: мост 1,4 с не воспринимается как ошибка; `Esc` возвращает на `L12`.
10. Клик по маркеру: приближение ступенчатое (прицел → захват → кадры → доводка), суммарно
    не дольше `1,5 с` на любой глубине; отмена колесом/`Esc` мгновенная, без «пружин».
11. Стрелки: ближайшая — первая по расстоянию от центра камеры; цели в кадре тоже получают
    стрелку (внутренний вид); `+n` совпадает с числом отсечённых; подпись «имя · N св.г.»
    видна без наведения, единица на месте и отделена неразрывным пробелом; на телефоне
    сдвиг стрелки не мешает попаданию пальцем.
12. Переход со стрелки читается как «отъехал → выровнялся → сместился → нырнул», укладывается
    в `1,5 с`; промежуточных кадров не больше трёх.
13. Системный кадр для системы с телами (Умоджа, Коло) и без тел (Корхал) — пустое
    состояние понятно.
14. Возврат из `/planet-globe/` восстанавливает адрес и уровень.
15. Публикация: нет растровых тайлов и исходника карты; `verify:publish` `7/7`.
16. Единицы: у стрелок, в счётчике `+n`, в досье и в карточке точки расстояния напечатаны
    в `св.г.` через `formatDistanceLy` (`88,4 св.г.`, `1 303 св.г.`), без `ly` и без `0,088`.
17. Территории: на `L8…L12` заливка сетей не превращается в пятно под маркером, контур
    читается, фон поля виден.
