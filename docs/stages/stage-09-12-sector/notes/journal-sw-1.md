## 2026-10-25 — Волна SW-1 слита: адрес KP·REQHC, 13 уровней, единый форматтер (гейты G7.1–G7.4)

Первая кодовая волна под-уровня Этапов 9–12 выполнена в параллельном режиме
(`Tri-Agent Wave`): Воркер 1 — PR #244 `c9c36b4`, Воркер 2 — PR #245 `86ded61`,
сквозной гейт Гайдлайнера — PR #248 `dd1f2ea`. Рантайм `/sector/` и планетарный контур
не менялись: построено ядро, на котором стоят `SW-2`/`SW-3`.

- **Адрес `KP·REQHC`** (`src/atlas/sector-address.ts`): кодек тиров `T0…T5`
  (`10 000 / 2 000 / 400 / 80 / 16 / 3,2` св.г., алфавит `A…Y`, ось `y` вниз) и верификатор
  `tools/verify_sector_address.mjs` (`npm run verify:address`): 173 системы —
  173 уникальных адреса уже на тире `16` св.г. (минимальная пара Зеф ↔ Орна —
  `50,01` св.г.), golden vectors `11/11`, максимум round-trip `0` св.г. — гейт **G7.1**.
- **13 уровней глубины** (`src/atlas/level-ladder.ts`): `L0…L9 + S0…S2`, пороги —
  точная геометрия `10 000 / 2ⁿ` (`10 000 / 5 000 / 2 500 / 1 250 / 625 / 312,5 / 156,25 /
  78,125 / 39,0625 / 19,53125` св.г.), `addressLetters` по уровням `0,1,2,2,3,3,4,4,5,5`,
  гистерезис `±12 %` — гейт **G7.2**.
- **Единый форматтер** (`src/atlas/sector-units.ts`): `formatDistanceLy` — единственный
  форматтер расстояний (`90,8 св.г.`, инвариант `И-16`), `pluralYears`, `formatAngleDeg` —
  гейт **G7.3**.
- **Гейт G7.4 (матрица проверок) на `main` после слияния:** `npm test` — 195 тестов,
  187 pass, 8 fail (все 8 — известная планетарная база Stage-8 вне задачи сектора,
  новых падений нет); сквозной `npm run verify:sector-core` — 3 032 проверки, 0 провалов
  (максимум расхождения `markerPx` `0,0448 px` на L1, отклонение центра узла
  `≤ 2,263` св.г.); `npx tsc --noEmit`, `npx eslint site src`, `npm run build`,
  `npm run verify:publish`, `git diff --check` — зелёные.
- **Два дефекта приёмки:** (1) `verify:address` стоял после `npm test` в одном shell-блоке
  `check.yml` и не запускался ни разу — в PR #248 верификаторы подняты выше `npm test`;
  (2) при пределе зума `19,53125` св.г. уровень `L9` недостижим из-за гистерезиса
  (вход `W(n)·0,88 = 17,1875`, выход до `21,875`) — это явное требование к `SW-3`:
  `MIN_REACHABLE_WIDTH = 17,1875` св.г. (`markerDiameter = 36,24 px` укладывается
  в кламп `40 px`), а не дефект `levelForWidth`. Следующая волна — **SW-2** (процедурное
  поле и вывод растра одним PR).
