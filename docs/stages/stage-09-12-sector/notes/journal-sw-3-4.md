## 2026-10-25 — SW-3-wire, остаток SW-4 и монтаж сцены сектора (после PR #265)

Работа после уже слитой документации SW-2 (`8e3fd1f`); содержание PR #265 здесь не повторяется. Утверждения ниже сверены с кодом коммитов `8880500`, `b39d1e1`, `fab350b`, `31ee897` и `147a0e2`.

- **Кламп зума** (`8880500`, PR #268): `CONFIG.view.maxFactor` удалён; потолок `maxScale()` равен `maxScaleForTargetEdge()` = `min(w,h)/2` px/св.г.; `centerOn()` ограничивает запрос интервалом `[minScale(), maxScale()]`, оба метода экспортированы. На пределе расстояние от цели в центре кадра до ближайшего края — ровно `1,00 св.г.`; пять viewport `1920×1080 / 1366×768 / 2560×1440 / 390×844 / 844×390` дают `540 / 384 / 720 / 195 / 195 px/св.г.`.
- **SW-4 остаток** (`b39d1e1`, PR #269): строка `1,00 св.г. до границы` показана под процентом зума. `?at=<адрес>&lw=<видимая ширина в св.г.>` использует ширину по горизонтали (`w/scale`); минимально достижимый `lw` — `2·w/min(w,h)`, то есть `3,56` на `1920×1080` и `2,00` на `390×844`, меньший запрос упирается в кламп. `?coords=1` включает координатный режим. `#system=<id>&frame=<S|O>` только разбирается и хранится, системный кадр не рисуется. Shift+клик открывает карточку точки; адресный поиск принимает `KP·REQHC`, `KP-R-E-Q-H-C`, `REQHC`.
- **Сцена**: `fab350b` добавил `sector-scene.ts`, `label-layout.ts` и 27 тестов (17 + 10) без проводки; `147a0e2` перевёл рендер на `buildSectorScene()`/`layoutLabels()`. Удалены `drawMarkers`, `drawMapLabels`, `markerMetrics`, `CONFIG.markerLod` и `CONFIG.hitRadius`; `worldFont: 38` / верхний `maxFont: 56` сменены экранным кеглем 11 px, общий бюджет — `LABEL_BUDGET = 120`. Диаметры: L0 `2,50 px`, L8 `25,67 px`, L10…L12 `40,00 px`. Порядок §8.1: поле → территории L2…L6 → сетка L1…L8 → маркеры → подписи → апертуры с L8.
- **Приёмка базы `147a0e2`**: `npm test` — 261 тест в 25 файлах, 253 pass и 8 известных планетарных fail (Stage-8/A-17/W26b); подключение четырёх секторных файлов в команду зафиксировано `31ee897`. `verify:sector-core` — 3 880; `verify:no-raster` — 9/9; `verify:publish` — 7 маршрутов / 36 hashed; `npm run build` прошёл.
- **Границы**: в песочнице нет WebGL2, GPU p95 и память поля не измерялись; проверка шейдера только структурная. Полёт/стрелки SW-3F и системный кадр SW-5 на базе `147a0e2` ещё не влиты.
