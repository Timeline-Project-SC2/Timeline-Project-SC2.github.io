## Что реализовано

| Артефакт | Назначение |
|---|---|
| `tools/planet_generation.py` | Единый контракт профилей: 37 колонок, 8 пресетов, валидатор, эффективный манифест, `generation_key`, CLI для seed/draft/manifest/key/freeze-row |
| `data/planet-generation.csv` | Начальный снимок нового листа: пока только канонический заголовок, профилей нет |
| `data/planet-generation-template.csv` | Шаблон для создания вкладки Google Sheets и два безопасных примера черновиков для существующих `places.ID` 2 и 5 |
| `data/sources.json` | Третий источник `planet-generation-sheet` включён; его CSV-URL собран из общего опубликованного токена книги и `gid=1183479406`. На момент включения живой лист содержит только заголовок |
| `tools/sync.py` | URL-источники переведены на двухфазную синхронизацию: скачать и проверить всё в памяти → только потом атомарно заменить снимки |
| `tests/test_planet_generation.py` | 26 автоматических тестов схемы, пресетов, ключа, валидатора и интеграционного гейта синка |
| `.github/workflows/check.yml` | Валидатор снимка и Python-тесты выполняются в каждом PR; наличие `data/planet-generation.csv` проверяется в публикации |

Боевые страницы пока не читают новый CSV. Это соответствует плану: Этап 2
закладывает данные и безопасную доставку, а страница планеты появится на
Этапах 6–7.
