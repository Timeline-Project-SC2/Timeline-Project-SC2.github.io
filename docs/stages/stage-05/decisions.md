## Решения этапа

**D5-1 · `geography_version=c100-soft-v2`** — полный рецепт: поля + континенты + гидрология + биомы. Версия v1 не переопределяется.
**D5-2 · Priority-flood + классификация впадин** вместо простого заполнения.
**D5-3 · Два уровня водосборов:** терминальные по фактическому дереву и дренажные регионы целевого масштаба.
**D5-4 · Дельты только у берега/шельфа;** речное влияние отдельным весом.
**D5-5 · 16 мягких биомов с top-2, энтропией и готовым CPU-цветом.**
**D5-6 · Валидатор и Transferable-контракт обязательны** для worker-пути.
