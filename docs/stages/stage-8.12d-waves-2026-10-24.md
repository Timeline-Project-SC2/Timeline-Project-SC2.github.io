# Stage-8.12d: волна «стенд вместо карточек» (24.10.2026)

## Зачем эта волна

Пять волн подряд закрывались по схеме «снимок владельца → находка → карточка →
починка». Схема даёт зелёные тесты при видимом браке: проверка мерила то, что
назвал дефект, а не то, что видит глаз. A-17b и A-29 — два случая подряд.

Меняем правило: **источник задач — измерительная таблица, а не кадр**. Снимки
владельца остаются только финальной приёмкой.

## База

Все ветки волны растут от **`a678096`** — вершины PR #227 (8.12b + A-29).
Причина: без единой семантики воды и батиметрии воротника чинить реки и фактуру
гекса не на чем. `main` (`c950179`) для этой волны базой не является.

**Почему реки и фактура у одного воркера.** Оба дефекта живут в одном файле
(`local-map-worker.ts`) и в одной функции построения heightfield. Разделить их
между воркерами — гарантированный конфликт; поэтому они последовательны внутри
W19, а не параллельны.

## Пороговые значения стенда

Значения заданы карточкой W18 и не меняются без согласования с Гайдлайнером:

| Метрика | Порог |
|---|---|
| Ступень кромки русла между соседними вершинами | ≤ 2 м |
| Глубина воды в центре русла | ≥ 3 м |
| Непрерывность русла через грань гекса | 16/16 азимутов |
| Отношение RMS рельефа «патч / воротник / юбка» | 0,7 … 1,3 |
| Максимальный перепад между соседними вершинами на суше | ≤ 6 м |
| Перепад `waterDepthM` патч/юбка на одинаковой глубине | ≤ 0,5 м |
