## Решения этапа

**D7-1 · Страница адресуется только стабильными query-параметрами** `place`, `system`, `cell`; ячейка — канонический адрес или индекс на `canonicalV`.
**D7-2 · Один источник ссылки — `planetGlobeUrl(place)`;** формат не дублируется.
**D7-3 · Ключ `PG1` проверяется при каждом открытии:** черновик → только черновая генерация, `frozen` → `L1 Frozen`, расхождение → отказ.
**D7-4 · `Patch7` — 7 канонических ячеек** и общий 3D-сэмплер; это контракт `И-3`, а не эвристика.
**D7-5 · Предзагрузка по намерению камеры** (debounce 180 мс), а не по каждому движению.
