## 10. Гейт G2

Последовательный bench без параллельной нагрузки:

```bash
node tools/bench_planet_stage4.mjs --seeds=5
```

| Метрика v=128 | Результат | Гейт |
|---|---:|---:|
| Mesh build, медиана | 439.6 мс | — |
| Поля + C100-soft, медиана | 913.1 мс | — |
| Mesh + география, медиана | 1 352.7 мс | ≤2 000 мс |
| Typed arrays сетки + географии | 33.45 МиБ | ≤64 МиБ |
| Validation на всех seed | true | true |
| Max abs ocean error | ≤0.000007 в ансамбле | ≤0.01 в bench |

Тот же bench добавлен в CI job `Planet CPU performance` на пяти seed.
30-seed ансамбли в CI не гоняются каждый PR из-за времени; они остаются
калибровочной командой и источником цифр этого отчёта.

Автоматические тесты Этапа 4:

- `tests/planet-geography.test.mjs` — xxHash32 и golden domain seed,
  snake_case/camelCase профиль, версии, golden sampler, детерминизм,
  ocean 0/100, gas giant/no-surface, async=sync, Transferable и порча
  мягких весов;
- `tests/test_planet_generation.py` — дефолты v1, канонические масштабы
  Земли, отказ от прототипных версий, новый golden PG1 и прежний синк;
- CI дополнительно запускает тесты ядра/кэша Этапа 3 и Stage 4 bench.

## 11. Ограничения и следующий этап

- Новый генератор пока нигде не рисуется. `/planet-test/` остаётся
  спайком на старом sampler; боевое подключение worker → глобус —
  Этапы 6–7. По URL спайка качество Этапа 4 глазами не проверяется.
- Гидрология и биомы отсутствуют: `drainage_mean_cells`, речные и
  биомные процентили только сохранены в профиле для Этапа 5.
- Гейт G2 измерен в Node для канонической Земли. Для планет существенно
  большего радиуса время и память растут с числом ячеек; предел полной
  генерации и chunk-стриминг остаются решениями Этапа 6.
- Async-генерация дробит только сэмплирование полей. В главном потоке
  финальные графовые фазы всё ещё могут занять сотни миллисекунд,
  поэтому продакшн-путь обязан быть воркером.
- Статистика доказывает масштабы, связность и отсутствие грубых
  артефактов, но не заменяет визуальную приёмку берегов и континентов
  на глобусе.

Следующий содержательный этап по плану — Этап 5: сток, впадины/озёра,
водосборы, дельты, горные швы и мягкие биомные веса поверх полей и
идентичностей `c100-soft-v1`.
