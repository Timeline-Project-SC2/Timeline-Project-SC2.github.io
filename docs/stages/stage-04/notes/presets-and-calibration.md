## 6. Пресеты v1

Каноническая Земля Этапа 3 — `v=128`, то есть в четыре раза больше ячеек,
чем стартовая калибровка `v=64`. Поэтому целевые массы в ячейках
механически умножены на 4, а линейные soft width в ячейках — на 2.
Дополнительно по ансамблям снижена `continent_variation` у сухих миров:
`desert_dry 0.7→0.5`, `ice_world 0.7→0.6`, `barren_moon 0.6→0.4`.

| Пресет | Континенты | Variation | Океан. бассейны | Водосбор* | Soft width берег/континент/биом |
|---|---:|---:|---:|---:|---:|
| `earthlike_balanced` | 400 | 0.8 | 6 000 | 72 | 3 / 4 / 2 |
| `earthlike_archipelago` | 180 | 1.0 | 4 400 | 48 | 2.4 / 2.8 / 1.6 |
| `ocean_world` | 100 | 1.1 | 10 000 | 32 | 4 / 2 / 2.4 |
| `desert_dry` | 560 | 0.5 | 2 000 | 120 | 1.6 / 5 / 1.4 |
| `ice_world` | 480 | 0.6 | 4 800 | 80 | 2.4 / 4 / 1.6 |
| `volcanic_active` | 280 | 1.2 | 3 600 | 56 | 1.4 / 2.4 / 1.4 |
| `barren_moon` | 720 | 0.4 | 6 000 | 200 | 0 / 2 / 1 |
| `gas_giant_bands` | 1 | 0 | 1 | 1 | 0 / 0 / 0 |

\* `drainage_mean_cells` пока только переносится профилем; фактические
водосборы строит Этап 5. Единицы у газового гиганта — служебные заглушки,
поверхностная география для него не генерируется.

`tools/planet_generation.py` теперь по умолчанию выдаёт все четыре
версии v1. Прототипные `planet-noise-spike-1`, `c100-soft-v0` и
`planet-presets-v0` валидатором больше не поддерживаются и не
переинтерпретируются как v1. Историческая `goldberg-gp-v0` для сетки
по-прежнему допустима явно как legacy, но генератор Этапа 4 принимает
только `goldberg-gp-v1`. Golden PG1 тестового профиля обновлён:
`PG1-D6CASVACAK3WKXTHZKSFX5HLCA`. Живых профилей и замороженных ключей
в `planet_generation` пока нет, поэтому миграция существующих планет не
требуется.

## 7. Калибровка: методика

Инструмент:

```bash
node tools/bench_planet_stage4.mjs --mode=ensemble --seeds=30 \
  --preset=earthlike_balanced --output=/tmp/stage4-earthlike.json
```

Bench читает пресеты из `tools/planet_generation.py presets --json`, то
есть не держит второй копии значений. Seed ансамбля детерминированно
выводится как первые 16 hex-цифр SHA-256 строки
`planet-stage4-calibration-v1|<preset>|<index>`.

Для каждого seed проверяются `validateGeography`, фактический океан,
мягкие доли, распределения эффективных масс, ядро/переходная зона,
энтропия, физические массивы при трёх порогах, климат, полосоватость по
координатным осям, память и время. Ансамбли по 30 seed прогнаны для всех
семи поверхностных пресетов на Земле `R=6371`, `v=128`.

## 8. Результаты для `earthlike_balanced`

Целевое логнормальное распределение при mean=400 и sigma=0.8 даёт
ориентиры P10≈104, median≈292, P90≈808, P99≈1 870. Фактический пул из
3 758 идентичностей на 30 планетах:

| Метрика | Факт |
|---|---:|
| Идентичностей на планету | ≈125.3 |
| Mean эффективной массы | 400.4 |
| P10 / median / P90 / P99 | 99 / 323 / 780 / 1 643 |
| Sigma, оценённая по P10/P90 | 0.805 |
| Доля ядра support (top1 ≥0.75), медиана по seed | 0.829 |
| Доля переходной зоны (entropy ≥0.5), медиана | 0.299 |
| Средняя энтропия, взвешенная support, медиана | 0.314 |
| Пустых идентичностей после обрезки | 0 |

Медиана на 11% выше идеальной логнормальной, P99 на 12% ниже; это
сознательно оставленный географический след барьеров и seed-размещения,
а не попытка насильно нарисовать аналитическое распределение поверх
карты. Среднее и общая ширина распределения попадают в цель.

Океанические бассейны: 19 на планету, mean 5 964 при цели 6 000,
P10/median/P90 = 3 080 / 5 518 / 9 626, пустых нет.

Океан и климат:

| Метрика | Факт |
|---|---:|
| Hard ocean при цели 0.70 | 0.700000; max abs error 0.000007 |
| Soft land / shelf / ocean, медианы | 0.303 / 0.015 / 0.683 |
| Температура экваториальной полосы, медиана | 0.842 |
| Температура полярной полосы, медиана | 0.393 |
| Корреляция температуры с инсоляцией | 0.913–0.935 |
| Std полос высоты по осям x/y/z, медианы | 0.044 / 0.044 / 0.043 |

Физические массивы суши, медианы по 30 seed:

| Порог `muLand` | Массивов | Медианный размер | Крупнейший | Доля крупнейшего | Массивов <5 ячеек |
|---:|---:|---:|---:|---:|---:|
| 0.35 | 99 | 22 | 10 148 | 0.184 | 20 |
| 0.50 | 151 | 6 | 8 574 | 0.173 | 67 |
| 0.65 | 111 | 11 | 6 796 | 0.159 | 39 |

Мелких островов много по счёту, но не по площади: при медианных 49–50
тыс. ячеек суши крупнейший массив обычно занимает только 16–18%, а все
массивы меньше пяти ячеек суммарно остаются долями процента суши.
Визуальную «зернистость» ещё предстоит оценить на боевом глобусе; если
она окажется шумом, а не архипелагами, это будет отдельная калибровка
detail-поля новой версией, а не тихая правка v1.
