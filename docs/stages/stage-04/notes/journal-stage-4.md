## 2026-10-21 — Этап 4: боевые поля и `c100-soft-v1`

Владелец разрешил Этап 4 фразой «Давай этап 4». Добавлен общий модуль
`site/shared/planet-geography.js`: единый sampler полей по направлению,
замороженный 3D simplex `planet-noise-simplex3d-v1`, xxHash32-разделение
16-hex master seed по доменам с golden-значениями, площадно-взвешенный
уровень моря, дробное расстояние до берега, мягкие суша/шельф/океан,
семь плит, C100-идентичности с top-2 и энтропией, океанические бассейны и
физические массивы суши. Пустые идентичности без top-1 ячеек в публичные
записи не попадают. Для газовых гигантов и тел без поверхности результат
явно `surfaceApplicable=false`, а не фиктивная карта.

Пресеты переведены на `planet-presets-v1` под Землю v=128: целевые массы
в ячейках ×4, soft width ×2; у `desert_dry`, `ice_world` и `barren_moon`
дополнительно снижена variation по ансамблям. Python-контракт по умолчанию
выдаёт все версии v1, прототипные шум/география/пресеты v0 отклоняются,
golden PG1 обновлён. Шаблон будущих архетипов синхронизирован с v1, но
по-прежнему не является источником синка.

Калибровка прогнана ансамблями по 30 seed для всех семи поверхностных
пресетов новым `tools/bench_planet_stage4.mjs`, который читает пресеты из
Python CLI. Для `earthlike_balanced`: 3 758 идентичностей, mean 400,4 при
цели 400, P10/median/P90/P99 = 99/323/780/1 643, sigma по P10/P90 = 0.805,
hard ocean 0.700000 при max abs error 0.000007. Последовательный G2-bench
на пяти seed дал median mesh+география 1 352,7 мс и 33,45 МиБ typed arrays
при гейтах 2 000 мс/64 МиБ; bench добавлен в CI. Полный отчёт —
`docs/stages/stage-4-fields-c100-soft.md`.

Гидрология, реки, водосборы и биомы не реализованы — это Этап 5. Новый
генератор также пока не подключён к `/planet-test/` и боевой странице:
спайк продолжает показывать старый визуальный sampler, а worker/render
интеграция относится к Этапам 6–7. Async API дробит только сэмплирование
полей; графовые фазы в продакшне должны жить в worker.
