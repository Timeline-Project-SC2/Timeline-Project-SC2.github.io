## Цель

Заморозить первый боевой генератор географии поверх ядра v1: непрерывные поля, море/шельф, плиты, континентальные идентичности, океанические бассейны.

## Входит

* единый sampler полей по направлению на сфере;
* 3D simplex + xxHash32-разделение master seed по доменам;
* уровень моря и шельф по площадно-взвешенным процентилям;
* мягкие суша/шельф/океан, дробное расстояние до берега;
* 7 плит и границы плит;
* C100-soft top-2, энтропия, эффективная масса, площадь;
* океанические бассейны;
* пресеты v1 под `v=128`;
* статистический bench и CI-гейт G2.

## Не входит

* гидрология, реки, водосборы, биомы — Этап 5;
* подключение к боевой странице и спайку — Этапы 6–7;
* визуальная приёмка берегов на глобусе.

## Ошибки этапа

### Ошибки этапа

**E4-1 · Чистый хэш на ячейку как генератор континентов отклонён.** Он даёт шум без связной суши; заменено непрерывным полем + мягкой идентичностью.
**E4-2 · Async-генерация дробит только сэмплирование.** Финальные графовые фазы могут занять сотни мс в главном потоке, поэтому боевой путь обязан идти через worker.
**E4-3 · Генератор нигде не рисуется.** `/planet-test/` остаётся на старом sampler; визуально качество Этапа 4 не проверить до Этапов 6–7.
**E4-4 · Пресеты нужно было перекалибровать** под `v=128`; массовая заморозка до этого запрещена.

## Решения этапа

### Решения этапа

**D4-1 · `noise_version=planet-noise-simplex3d-v1`** — боевой 3D simplex.
**D4-2 · Подseed домена — `xxHash32(master_seed, domain)`;** master seed — ровно 16 hex.
**D4-3 · Уровень моря и шельф — площадно-взвешенные процентили,** а не доля ячеек.
**D4-4 · C100-soft:** top-2 принадлежность, энтропия, эффективная масса; идентичность не бинарная.
**D4-5 · Семь плит;** граница плит — вход для вулканизма и стоимости перехода.
**D4-6 · Пресеты v1 калиброваны под Землю `v=128`;** пустые поля раскрываются из пресета.
**D4-7 · G2 — статистический гейт ансамблей,** а не один seed.

## Журнал этапа

### 2026-10-21 — Этап 4: боевые поля и `c100-soft-v1`

Владелец разрешил Этап 4 фразой «Давай этап 4». Добавлен общий модуль
`site/shared/planet-geography.js`: единый sampler полей по направлению,
замороженный 3D simplex `planet-noise-simplex3d-v1`, xxHash32-разделение
16-hex master seed по доменам с golden-значениями, площадно-взвешенный
уровень моря, дробное расстояние до берега, мягкие суша/шельф/океан,
семь плит, C100-идентичности с top-2 и энтропией, океанические бассейны и
физические массивы суши. Пустые идентичности без top-1 ячеек в публичные
записи не попадают. Для газовых гигантов и тел без поверхности результат
явно `surfaceApplicable=false`, а не фиктивная карта.

Пресеты переведены на `planet-presets-v1` под Землю v=128: целевые массы
в ячейках ×4, soft width ×2; у `desert_dry`, `ice_world` и `barren_moon`
дополнительно снижена variation по ансамблям. Python-контракт по умолчанию
выдаёт все версии v1, прототипные шум/география/пресеты v0 отклоняются,
golden PG1 обновлён. Шаблон будущих архетипов синхронизирован с v1, но
по-прежнему не является источником синка.

Калибровка прогнана ансамблями по 30 seed для всех семи поверхностных
пресетов новым `tools/bench_planet_stage4.mjs`, который читает пресеты из
Python CLI. Для `earthlike_balanced`: 3 758 идентичностей, mean 400,4 при
цели 400, P10/median/P90/P99 = 99/323/780/1 643, sigma по P10/P90 = 0.805,
hard ocean 0.700000 при max abs error 0.000007. Последовательный G2-bench
на пяти seed дал median mesh+география 1 352,7 мс и 33,45 МиБ typed arrays
при гейтах 2 000 мс/64 МиБ; bench добавлен в CI. Полный отчёт —
`docs/stages/stage-4-fields-c100-soft.md`.

Гидрология, реки, водосборы и биомы не реализованы — это Этап 5. Новый
генератор также пока не подключён к `/planet-test/` и боевой странице:
спайк продолжает показывать старый визуальный sampler, а worker/render
интеграция относится к Этапам 6–7. Async API дробит только сэмплирование
полей; графовые фазы в продакшне должны жить в worker.

## Исходный план (первоисточник)

### Этап 4. Поля и C100-soft

- Высота, влажность, температура, плиты.
- Мягкие суша/шельф/океан.
- Континентальные идентичности и океанические бассейны.
- Статистическая калибровка с буфером.
- Worker-контракт: все крупные буферы (>1 КБ) между worker и main thread
  передаются только как Transferable через
  `postMessage(data, [buffer, ...])`, а не structured clone. Если обе
  стороны должны владеть данными, владение явно разделяется версиями или
  буфер пересоздаётся из детерминированного рецепта; молчаливое
  клонирование больших типизированных массивов считается дефектом review.
  SharedArrayBuffer не является базовым путём: GitHub Pages не позволяет
  выставлять нужные `Cross-Origin-Opener-Policy: same-origin` и
  `Cross-Origin-Embedder-Policy: require-corp`, поэтому боевой транспорт —
  только Transferable.

**Гейт G2:** ансамбль seed проходит географические метрики.
Performance-критерии G2 в CI-окружении baseline: median
`mesh build + field calculation + C100-soft` для v=128 <=2000 мс
(текущий baseline без C100: 923+174=1097 мс), детерминированная память
ядра `grid + field SoA` для v=128 <=64 МиБ без GPU-геометрии, а главный
поток не блокируется кусками дольше 50 мс, потому что поля считаются
worker-чанками.

**Факт Этапа 4 (актуализировано по `CR-01` PR #131, #137, #139):** реализовано в строгих TS-модулях `site/shared/planet-noise.ts` и `site/shared/planet-geography.ts` поверх гибридного Wasm-ускорителя `src/planet/assembly/kernels.ts` + `src/planet/planet-core-host.ts` (два скомпилированных модуля в `src/planet/planet-core-bytes.ts`: полное SIMD128-ядро `PlanetCore` для воркера/Node с общей ареной 24 МиБ и компактное `PlanetNoiseCore` `< 4 КиБ`, доступное синхронно на главном потоке без нарушения лимита Chrome; каноническая частота `canonicalV` строго удерживается по Инварианту И-1), едином контракте пресетов `src/contracts/planet-generation-contract.json` (`planet-presets-v1`, И-4), `tools/bench_planet_stage4.mjs` и тестах `tests/planet-geography.test.mjs`. В `makeWeightedQuantiles`, `chooseSeeds` и приоритетных очередях действует Wasm radix-сортировка и строгий целочисленный tie-break `a - b` по каноническому индексу ячейки (Инвариант И-2). Ансамбль 30 seed `earthlike_balanced`: mean эффективной массы 400,4 при цели 400, sigma по P10/P90 0.805, hard ocean 0.700000 при max abs error 0.000007, пустых публичных идентичностей нет; typed arrays сетки+географии — 33,45 МиБ при 100 % побитовой эквивалентности FULL EQ. Полный контракт — в `docs/stages/stage-4-fields-c100-soft.md`.
