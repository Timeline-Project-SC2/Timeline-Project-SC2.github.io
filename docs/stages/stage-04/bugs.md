## Баги этапа

**B4-1 · «Невидимый» этап.** Новый генератор не подключён к странице — риск, что ошибки поля всплывут только на Этапе 6.
**B4-2 · Рост времени и памяти с радиусом.** Гейт измерен только для Земли `v=128`; большие радиусы требуют chunk-стриминга.
**B4-3 · Статистика не заменяет визуальную приёмку** берегов и континентов.
