## Ошибки этапа

**E1-1 · Value noise даёт суперконтинент.** На всех частотах один массив занимал 84–85 % суши. Гипотеза «value noise достаточно» отклонена в пользу градиентного семейства.
**E1-2 · Адрес v0 не был каноническим.** Владелец рёберной вершины — первая грань обхода; публичные ссылки на таком адресе выпускать нельзя. Исправлено в Этапе 3 (`goldberg-gp-v1`).
**E1-3 · Метка выбранной ячейки не сбрасывалась после смены LOD.** Примеры: текущий `v=34` при адресе `v=128`, `v=24` при `v=64`. Подпись надо пересчитывать/сбрасывать вместе с уровнем.
**E1-4 · Заголовок сворачиваемой панели уезжал за верхний край.** Кнопка `−/+` прокручивалась вместе с содержимым; заголовок нужно закрепить.
**E1-5 · Прокси не показывался при `v≤64`.** Первые 0,3–0,5 с — пустой канвас; лечится порогом показа прокси.
**E1-6 · Синхронная генерация `v=192` давала ~3 с мёртвого ожидания.** Исправлено worker-ом и прокси-планетой.
**E1-7 · Заливка буферов полной геометрии осталась синхронной.** ~2,6 млн вершин при `v=192`; чанковая загрузка — следующий шаг.
