### Открытые вопросы Этапа 1

- [ ] FPS при v=128 и v=192 на десктопе владельца и на телефоне → зафиксировать
      каноническую плотность Земли (64 / 128 / 192).
- [ ] Перефиксировать размер континента в ячейках под выбранную плотность.
- [ ] Стриминг чанками (п.5) vs текущий прокси — решение владельца.
- [ ] Двойной каскад «прокси → финал»: оставить, укоротить вторую волну или
      подменять без неё (вкусовой вопрос владельца).
- [ ] Закрыть визуальную часть гейта G1 полностью (вид планет на нескольких
      seed, читаемость сетки, удобство на телефоне, simplex vs value глазами).
- [ ] Закоммитить спайк и открыть PR по ветке `arena/c6424c78-…`
      (с записью в `CHANGELOG.md` по конвенции репозитория).
- Далее по плану: Этап 1.5 — переход глобус → локальная плоскость.

Дополнено ревизией 19.10 (сверка объёма спайка с фактом; критичных пропусков
не найдено, ниже — мелочи):

- [ ] DPR в панели не вынесен: стоит фиксированный кап 1.75 в `resize()`.
      Ручной ползунок пригодился бы для тестов мобильной нагрузки — на
      усмотрение владельца.
- [ ] Статистика массивов суши замерена только до v=100 (чекер). При выборе
      канонической плотности 128/192 распределение массивов проверить там же.
- [ ] Точный порт OpenSimplex2S vs текущий simplex — решение отложено до
      заморозки `noise_version`; текущее поведение запиннено golden-значениями.
- [ ] Замер памяти в браузере — только оценка буферов GPU в статистике;
      JS-heap (`performance.memory`, Chrome-only) на страницу не выведен.
- [ ] Первый показ при v≤64 через воркер: прокси не показывается, ~0,3–0,5 с
      пустого канваса при первой загрузке. Косметика, чинится порогом прокси.

### Известные ограничения спайка (напоминание)

- Адреса ячеек — черновик v0 (владелец рёберной вершины — первая грань
  обхода); канонизация — Этап 3, до публичных ссылок.
- Биомы — грубая раскраска для читаемости; рек, водосборов и идентичностей
  C100 нет (Этапы 4–5).
- Очередь воркера нельзя прервать внутри одного запроса; устаревшие ответы
  отсекаются токеном генерации.
- Нет fallback при отсутствии WebGL2 (Этап 6).
