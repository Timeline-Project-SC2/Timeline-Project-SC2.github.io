## 2026-10-20 — пометка: мобильная LOD-пирамида до Этапа 3

После мержа PR #115 владелец сообщил, что спайк на телефоне работает, но
подлагивает, и предложил уровни качества по аналогии с растровой картой:
чем ближе камера, тем детальнее гексы. До начала Этапа 3 в `planet-spike-18`
сделан отдельный render-эксперимент:

- панельная `v` стала максимумом; авто-LOD выбирает уровень из лестницы
  16/24/34/48/64/80/100/128/160/192 по целевому экранному размеру гекса
  около 11 CSS-px, с гистерезисом 8–15 px;
- уровни используют одни непрерывные поля, кэшируются по параметрам и
  готовятся воркером поверх текущего кадра; подмена — короткая волна из
  центра на 350 мс без повторного каскада;
- для телефона добавлен адаптивный внутренний масштаб рендера: старт не
  выше 1.50× на coarse pointer, снижение до 0.60× при FPS < 38 и осторожный
  подъём при стабильных >57 FPS;
- фиксированный режим отключает LOD и динамический масштаб для чистых
  замеров плотности.

Граница эксперимента: это глобальный LOD всей сферы, а не chunk-LOD по
граням и не выбор канонической плотности. При близком виде высокий уровень
пока строится целиком; пространственная детализация и пропуск невидимых
чанков остаются на Этап 6. Канонические адреса и плотность по-прежнему
фиксируются Этапом 3 и замерами владельца.
