## Этап 1 — спайк гексагонального глобуса (19.10.2026)

**Статус:** техническая часть гейта G1 закрыта проверками; визуальная приёмка
владельца — десктоп подтверждён, телефон не проверялся. Код — ветка
`arena/c6424c78-timelineprojectsc2-github-io`, пока без коммита.
Боевые страницы не затронуты.

### Что построено

- `site/shared/geodesic-grid.js` — Goldberg GP(v,0) для произвольного целого v:
  ячейки, углы, соседи, сферические площади, черновые адреса
  `goldberg-gp-v0/w0/v64/f07/a18/b31` (w — резерв тела, см. п.13), пикинг полным перебором, `validate()`.
- `site/shared/planet-noise.js` — детерминированные поля по 3D-направлению:
  градиентный simplex и собственный value noise, fBm, касательный domain
  warp; сэмплер «высота/влажность/температура».
- `site/planet-test/` — изолированная страница спайка: WebGL2-глобус (веер из
  центра ячейки, граница по весу центра, атмосфера), вращение/зум/pinch,
  выбор ячейки кликом, панель параметров, статистика, FPS.
- `site/planet-test/planet-worker.js` — воркер генерации (см. ниже).
- `tools/check_planet_spike.mjs` — топология, детерминированность (golden
  values), статистика суши. `tools/bench_planet_density.mjs` — модель
  плотности.

### Решения и установленные факты

- Собственная топология работает на произвольном v; запасной путь H3 не нужен.
- **Шум: simplex, не value.** Value на всех частотах слипается в суперконтинент
  (один массив = 84–85% суши); simplex даёт ~17% на крупнейший массив и ~111
  массивов на медианной планете. Стартовые параметры: freq 2.2, 5 октав,
  gain 0.5, warp 0.35, океан 70%.
- Поля сэмплируются по направлению и **не зависят от v**: одна и та же планета
  на любом разрешении сетки. От v зависят только адресация ячеек и семантика
  «континент из N ячеек».
- Пикинг полным перебором достаточен даже при v=192 (0,94 мс на клик);
  ускорение по граням понадобится только для hover-подсветки каждый кадр.
- Стартовая точка калибровки: Земля v=64 → 40 962 ячейки, средняя ячейка
  12 452 км², ребро ≈ 69 км. Под вопросом (см. модель ×8–9 ниже).
