## Решения этапа

**D1-1 · Собственная сетка `GP(v,0)`, не H3.** Произвольное `v` строится быстро; H3 остаётся эталоном сравнения.
**D1-2 · Градиентный simplex, не value noise.** Больше отдельных массивов суши и когерентная береговая линия.
**D1-3 · Стартовые параметры полей:** частота 2,2, 5 октав, warp 0,35, океан 70 %.
**D1-4 · Тяжёлая генерация — в Web Worker, при `v>64` сразу показывается прокси `v=32`.**
**D1-5 · LOD-пирамида 16/24/34/48/64/80/100/128/160/192,** целевой средний гекс ~11 CSS-px, гистерезис 8–15 px; поля не зависят от `v`.
**D1-6 · Мобильный рендер:** внутренний масштаб ≤1,5×, пол 0,60×, анти-хантинг по p95.
**D1-7 · Темы — только render-слой.** Seed, уровень моря, биомы, адреса и `generation_key` не меняются.
