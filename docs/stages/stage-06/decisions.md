## Решения этапа

**D6-1 · Генерация — в Web Worker;** главный поток только рендерит.
**D6-2 · Прокси → финал** с волной из центра; две полные сферы не живут постоянно.
**D6-3 · Адаптивное качество** по FPS, но с удержанием во время загрузки.
**D6-4 · Мобильный финал `v=64`, прокси `v=24`;** DPR ≤1,5; заливка порциями.
**D6-5 · Страница объявляет готовность только после фактической подмены VAO.**
**D6-6 · Chunk-culling не входит в Этап 6:** рендер строит всю сферу, это долг Этапа 7/8 и последующих оптимизаций.
