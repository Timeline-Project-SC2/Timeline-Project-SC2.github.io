# Этапы: паспорта и регистры

Каждый этап — папка `stage-NN/` с единым паспортом
[`plan.md`](stage-00/plan.md): план, секции «Ошибки», «Баги», «Решения»,
«TODO», журнал и исходный план-первоисточник живут в нём по гибридной
модели консолидации. Отдельный файл регистра (`errors.md`, `bugs.md`,
`decisions.md`, `todo.md`) заводится только когда секция паспорта
перерастает ~60 строк или самостоятельно цитируется — такие выносы
помечены прямо в паспорте. У папок `notes/` с приложениями есть индекс
`notes/README.md` с заметками в порядке чтения; у этапов без приложений
папки `notes/` нет. Правила типов — в [`../README.md`](../README.md).

Назад: [документация](../README.md).

## Как читать этап

1. `plan.md` — паспорт целиком: что хотели, какой гейт и статус, почему
   сделано именно так (секция «Решения»), что ломалось («Ошибки»/«Баги»)
   и что осталось («TODO»). Вынесенные по порогу гибрида регистры лежат
   рядом файлами и помечены в паспорте.
2. `notes/` — детали и замеры, только по ссылке из паспорта или индекса
   папки; читать по глубине не дальше приложения к профильному файлу.
