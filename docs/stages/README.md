# Этапы: паспорта и регистры

Каждый этап — папка `stage-NN/` с пятью файлами:
[`plan.md`](stage-00/plan.md) (ПЛАН), `errors.md` (ОШИБКИ), `bugs.md` (БАГИ),
`decisions.md` (РЕШЕНИЯ), `todo.md` (TODO) и папкой `notes/` с приложениями.
У каждой папки `notes/` есть индекс [`notes/README.md`](stage-00/notes/README.md)
с описанием всех заметок. Правила типов — в [`../README.md`](../README.md).

Назад: [документация](../README.md).

## Как читать этап

1. `plan.md` — что хотели, что вошло, какой гейт и статус.
2. `decisions.md` — почему сделано именно так (ID и ссылки).
3. `errors.md` / `bugs.md` — что сломалось и чему научились.
4. `todo.md` — что уже работает и что осталось.
5. `notes/` — детали и замеры, только по ссылке из паспорта.
