# Зерус — пре-сиды планетной генерации

> **Дата:** 21 октября 2026.
> **Статус:** пре-сид для `planet_generation` (черновик уровня `review`).
> Это **не** заморозка и **не** палитра сайта: строки подготовлены мной,
> владелец вставляет их в Google Sheets сам.

Референс — скриншот заказчика (`assets/overview.png`, слева): beauty-рендер
планеты в оранжевой туманности. Дымка, облака и туманность на картинке —
это оформление, а не геометрия, поэтому сиды **не подгонялись под точное
расположение пятен**. Задача была другой: дать несколько независимых
воспроизводимых миров с характером Зеруса — джунгли, океаны, вулканизм,
горы — и полный набор строк для таблицы.

## 1. Что лежит в этой папке

| Файл | Что это |
|---|---|
| `planet-generation.row-A.csv`, `-row-B.csv`, `-row-C.csv` | три готовые **альтернативные** строки для вкладки `planet_generation` (канонический заголовок из 37 колонок, по одной строке в файле) |
| `places.example.csv` | пример строки `places` для Зеруса (`ID=1000`, `system_id=99`); нужен только чтобы строки `planet_generation` проходили проверку внешнего ключа — реальные ID выдаёт таблица проекта |
| `assets/row_A.json`, `row_B.json`, `row_C.json` | те же строки в JSON, по одной |
| `assets/zerus_*.json` | статистика мира и «якоря» ландшафтных объектов: адрес ячейки, широта/долгота |
| `assets/zerus_*_hero.png` | ортографический «портрет» планеты (640×640) |
| `assets/zerus_*_views.png` | три ракурса через 120° (400×400 каждый) |
| `assets/zerus_*_map.png` | равнопромежуточная развёртка (1024×512) с подписями якорей |
| `assets/overview.png` | эталон и три варианта на одном листе |

География всех картинок посчитана **тем же кодом**, что и боевой глобус
(`geodesic-grid` → `planet-geography` → `planet-surface`), напрямую в Node
на `v=96` (92 162 ячейки, каноническая частота для 6200 км — `v=125`).
Нарисованы они моим ортографическим рендером: палитра, дымка и свечение —
оформление визуализации, а рельеф, биомы, реки, озёра и горы — чистый
выход генератора. Это «примерная визуализация», а не превью сайта: у
страницы `/planet-globe/` своя палитра, освещение и камера.

## 2. Три варианта

Общий профиль у всех трёх (все 19 географических чисел заполнены явно,
чтобы строка не зависела от будущих правок пресета):

```text
preset_id=volcanic_active   surface_class=volcanic   radius_km=6200
continent_mean_cells=420    continent_variation=0.9  ocean_basin_mean_cells=5200  drainage_mean_cells=48
ocean_pctl=50  shelf_below_pctl=46  shelf_above_pctl=54
highland_land_pctl=76  mountain_land_pctl=92
arid_land_pctl=6  wet_land_pctl=44  cold_pctl=2  hot_pctl=56
stream_flow_pctl=88  major_river_flow_pctl=98.5
coast_soft_width_cells=2.4  continent_soft_width_cells=3.0  biome_soft_width_cells=1.6
transition_entropy_pctl=90
```

Почему так: класс `volcanic` усиливает вулканический биом (×1.8) и
приглушает растительность (×0.65), поэтому джунгли не закрывают материк
целиком и сквозь них видны швы. Влажный край `wet_land_pctl=44` при сухом
`arid_land_pctl=6` оставляет джунгли основным ландшафтом, `ocean_pctl=50`
отдаёт примерно половину поверхности под воду, а `mountain_land_pctl=92`
держит горы редкими, но высокими — «джунгли, океаны, моря и вулканы».

| | seed | наклон / сутки | характер | суша | хребты | озёра | речные регионы |
|---|---|---|---:|---:|---:|---:|---:|
| **A** | `fd51abcae100d5b1` | 18.4° / 22.5 ч | самый влажный: максимум джунглей, ровный рельеф | 0.501 | 17 | 454 | 1293 |
| **B** | `e41a7b0c25d89367` | 21.7° / 26.0 ч | самый гористый: крупнейшие швы и хребты, 505 озёр | 0.498 | 16 | 505 | 1310 |
| **C** | `18ea7f3f8c99152d` | 15.9° / 19.5 ч | крупнейший речной бассейн и большое озеро | 0.501 | 15 | 490 | 1300 |

Доли биомов (v=96, доля всех ячеек):

| биом | A | B | C |
|---|---:|---:|---:|
| дождевой лес | 0.116 | 0.124 | 0.115 |
| умеренный лес | 0.110 | 0.108 | 0.121 |
| тайга | 0.059 | 0.050 | 0.045 |
| степь | 0.051 | 0.052 | 0.059 |
| высокогорье | 0.060 | 0.059 | 0.060 |
| жаркая пустыня | 0.041 | 0.034 | 0.038 |
| вулканический биом | 0.001 | 0.001 | 0.001 |

Вулканический **биом** занимает доли процента: он выигрывает только на
сильных швах. Вулканизм при этом виден по `mountainSeamWeight` и
`volcanism` — именно на них построено оранжевое свечение на картинках.

## 3. Готовые строки

Каждый файл — канонический заголовок плюс **одна** строка. В таблицу идёт
только один из них: валидатор запрещает два профиля на одно `place_id`
(`дублирующийся профиль для place_id`), так что три варианта — это
конкурирующие ревизии, а не три строки сразу. Каждый файл проходит
валидатор проекта без предупреждений:

```bash
for k in A B C; do
  python3 tools/planet_generation.py validate \
    --profiles docs/zerus/planet-generation.row-$k.csv \
    --places docs/zerus/places.example.csv
done
# OK: профилей проверено: 1; предупреждений: 0   (три раза)
```

Ключи `PG1` посчитаны штатным CLI и лежат в колонке `generation_key`:

- A — `PG1-CS6VOKORWX3SOFJXEEAMQ6CBGI`
- B — `PG1-ZVIDIB7745BMRBD5YSKYHB2MRM`
- C — `PG1-PHNVBJMYKXHOTA4SSL5EO4B2GY`

Что поправить перед вставкой в живую таблицу:

1. `place_id=1000` — заглушка. В живой `places` нужен реальный `ID` Зеруса,
   иначе валидатор синка отвергнет строку.
2. `profile_status=review`, `approved_by`/`approved_at` пустые. `frozen`
   ставит владелец после приёмки, тогда же `freeze-row` пересчитает ключ.
   Пересчитывать ключ нужно и при смене `place_id` или `profile_revision`.
3. `palette_id=zerus_jungle_ember` — новый код палитры. Сейчас он только
   проходит проверку формата; рендер палитру ещё не читает, это задел под
   `planet_customizations`.
4. Три варианта — это три конкурирующие ревизии **одного** места. В таблицу
   идёт одна строка, остальные остаются здесь как альтернативы: заменяйте
   строку целиком, а не добавляйте вторую.

## 4. Как посмотреть сам мир

Черновик можно подставить в боевой глобус, не дожидаясь таблицы. Страница
`/planet-globe/` строит профиль из значений пресета, поэтому её ссылка
воспроизводит **другой** профиль, чем строка: числа выше отличаются от
`volcanic_active` из контракта (мой профиль мягче по суше и заметно
влажнее). Поэтому ссылка ниже полезна как «посмотреть характер мира»,
а точная картинка — в `assets/`.

```text
/planet-globe/?preset=volcanic_active&seed=fd51abcae100d5b1&planet=zerus&radius=6200&surface=volcanic
/planet-globe/?preset=volcanic_active&seed=e41a7b0c25d89367&planet=zerus&radius=6200&surface=volcanic
/planet-globe/?preset=volcanic_active&seed=18ea7f3f8c99152d&planet=zerus&radius=6200&surface=volcanic
```

Проверка `generation_key` на странице появится тогда, когда глобус начнёт
читать `planet_generation.csv`: сейчас страница ключ не проверяет.

## 5. Якоря ландшафтных объектов

По лору у Зеруса есть Первый нерестовый бассейн, Вечный шрам, Фулмические
нагорья, Расколотая долина, Неукротимый шпиль и Нестабильная расщелина.
Чтобы их можно было привязать к реальным ячейкам, для каждого варианта
посчитаны «якоря» — ячейка, её канонический адрес и координаты:

| объект | что берётся | A (широта, долгота) |
|---|---|---|
| Фулмические нагорья | самая высокая точка суши | 3.53°, −137.53° |
| Вечный шрам | центроид крупнейшего горного хребта | 41.47°, −8.84° |
| Расколотая долина | самая глубокая впадина | 47.69°, 35.44° |
| Неукротимый шпиль | максимум `mountainWeight` | 64.69°, 174.86° |
| Нестабильная расщелина | максимум `volcanism` | 9.87°, 150.93° |
| Первый нерестовый бассейн | крупнейшее озеро | 31.05°, 178.64° |
| Великая река | устье крупнейшего дренажного региона | 18.27°, −158.46° |

Полные таблицы (адреса `goldberg-gp-v1/w0/v96/...` и значения) — в
`assets/zerus_A.json`, `zerus_B.json`, `zerus_C.json`. Адреса указаны для
`v=96`; при переходе на каноническое `v=125` их нужно пересчитать, а
широта/долгота останутся теми же.

## 6. Как это проверялось

```bash
# схема, перечисления, порядок процентилей, внешний ключ и ключ PG1
for k in A B C; do
  python3 tools/planet_generation.py validate \
    --profiles docs/zerus/planet-generation.row-$k.csv \
    --places docs/zerus/places.example.csv
done
```

География вариантов считалась модулями `site/shared/planet-geography.js` и
`planet-surface.js` напрямую в Node, на `v=96`; каноническая частота для
радиуса 6200 км — `v=125`, поэтому в строках нормы «в ячейках» заданы для
канонической частоты, как требует контракт.

## 7. Что дальше

- Выбрать вариант (A — самый «джунглевый», B — самый гористый, C — самый
  речной) и вставить одну строку в вкладку `planet_generation`.
- Если нужен другой характер мира: менять `wet_land_pctl`/`arid_land_pctl`
  (влажность), `ocean_pctl` (доля воды), `mountain_land_pctl` (горы), а
  `master_seed_hex` — только для поиска нового рисунка континентов.
- `planet_customizations` пока не читается синком, и `palette_id` сейчас
  влияет только на формат строки. Когда лист включат, `zerus_jungle_ember`
  можно будет раскрыть там в конкретные значения палитры и текстур.
