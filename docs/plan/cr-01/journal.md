## 2026-10-22 — План CR-01 (PR #129–#140), волна PR 6.1 (#145–#147, #152–#153) и волна DX-1 (#148–#151)

Перед выходом на страницы планеты и локальной карты репозиторий прошёл полную
инженерную модернизацию стека по плану `docs/CHANGE_REQUEST_PLAN.md` (**CR-01**)
с фиксацией инвариантов идентичности **И-1…И-6**:

- **Серия CR-01 (`PR #129–#140`):**
  - `PR #129` зафиксировал архитектурный план модернизации и критерии побитовой
    идентичности `c100-soft-v2` (И-1…И-6); в параллельных документационных
    коммитах обновлены пре-сиды Зеруса (`PR #132`), памятки для игроков
    (`PR #134`, `#136`), очистка внешних материалов (`PR #135`) и корневой
    `README.md` (`PR #140`);
  - `PR #130` (CR-01 PR 1) перевёл сборку и публикацию всех 7 маршрутов на
    строгий **TypeScript + Vite** в `.publish/` с контент-хэшами бандлов и
    манифестом `build-manifest.json`;
  - `PR #131` (CR-01 PR 2) выделил единый декларативный контракт
    `src/contracts/planet-generation-contract.json` и кросс-верификатор
    `tools/verify_planet_contract_cross.mjs` между Python и TypeScript (`PG1`);
  - `PR #133` (CR-01 PR 3) разрезал монолит атласа сектора (`/sector/`,
    `/minimal/`) на типизированные модули `src/atlas/*` и единый HTML-шаблон
    `templates/atlas-shell.html`;
  - `PR #137` (CR-01 PR 4) ввёл единое вычислительное ядро `planet-core` на
    **AssemblyScript / WebAssembly** и закрепил мобильную идентичность И-1 на
    канонической сетке `canonicalV`;
  - `PR #138` (CR-01 PR 5) консолидировал боевой и тестовый глобусы на едином
    `site/shared/planet-globe.ts` с опциональным FX-плагином
    `src/planet/planet-globe-fx.ts` (И-5, И-6), распилил
    `temp_code_structures.js` на 4 типизированных модуля `src/local-map/*` и
    реализовал контракт сшивки 7 ячеек `Patch7` (`local-map-contract.ts`, И-3);
  - `PR #139` (CR-01 PR 6) подключил Wasm radix-sort, arena pipeline, SIMD
    `f64x2` simplex и ускорил `GeodesicGrid.build(v)` в ~3,5×, доведя полную
    генерацию канонической Земли `v=128` до **≥3× быстрее baseline (`≤ 855 мс`)**
    при 100 % побитовом совпадении (`FULL EQ` и `CRC32C`).
- **Регламент оркестрации и волна PR 6.1 (`PR #141`, `#144–#147`, `#152–#153`):**
  - в `PR #141`, `#144` оформлен регламент параллельной сплит-разработки
    `Tri-Agent Wave` / `Split-Work` с матрицей `Zero File Overlap`;
  - первая тройка воркеров (`PR #145–#147`) мигрировала `planet-geometry` на
    строгий TS, перевела шарды осколков на клеточный индекс с объёмом разломов и
    светящимся ядром Шакураса, вернула на `/planet-test/` каскадные анимации
    `uBuild` / `uHide` / `uCenterGrow` и синхронизировала `PREPARATION_PLAN.md`;
  - хотфиксы `PR #152–#153` закрыли стык `onGeometryReady` / `vertexCellId` и
    канонические `surfaceClass` / `presetId` на `/planet-test/`.
- **Инфраструктурная волна DX-1 (`PR #142–#143`, `#148–#151`, черновик `#150` закрыт):**
  - зафиксированы версии среды (`.nvmrc` Node 24, `.python-version` Python 3.12,
    `typescript@^7.0.2`), сборочный конвейер декомпозирован на модули
    `tools/vite/*`, в `tools/sync.py` добавлен режим `--strict`, а правила
    репозитория разнесены по иерархии доменных `AGENTS.md` (SSoT).
