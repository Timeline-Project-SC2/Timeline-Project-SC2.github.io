## 8. Данные: дополнительная таблица, процентили и ключ фиксации

### 8.1. Общая схема потоков

```text
Google Sheets: systems ─┐
Google Sheets: places ──┼─ tools/sync.py ─► data/*.csv ─► сайт
Google Sheets: planet_generation (новый лист) ─┘

assets/src ─ tools/build_assets.py ─► производные assets ─► сайт
site/ ────────────────────────────────────────────────────► сайт
```

Новая таблица не заменяет `places`. Она является профилем генерации для тех мест, у которых есть поверхность.

Рекомендуемые имена:

- вкладка Google Sheets: `planet_generation`;
- снимок: `data/planet-generation.csv`;
- внешний ключ: `place_id`.

В текущем листе `places` заголовок называется `ID`. В новой таблице следует использовать именно `place_id`, а значение должно **посимвольно совпадать** со значением `places.ID`. Менять существующие ID нельзя.

### 8.2. Кому нужна строка профиля

| `places.type` | Профиль генерации |
|---|---|
| `planet` | Да, если нужен глобус |
| `moon` | Да, если нужен глобус |
| `asteroid` | Не в MVP; возможен упрощённый профиль позже |
| `station` | Нет |
| `platform` | Нет |
| `other` | Только если вручную отнесено к телу с поверхностью |

Отсутствие строки означает одно из двух состояний, которое нужно зафиксировать в реализации:

- глобус недоступен;
- либо доступен только автоматический черновой предпросмотр.

Рекомендация: публичный замороженный глобус требует явной строки со статусом `frozen`. Автоматический черновик может существовать в инструменте предпросмотра, но не должен выдаваться за утверждённую географию.

### 8.3. Схема листа `planet_generation`

Кодовая часть этой схемы реализована на Этапе 2 как контракт из 37 колонок в `tools/planet_generation.py`; актуальные правила и детали — в отчёте Этапа 2. Живая вкладка `planet_generation` (`gid=1183479406`) подключена в `data/sources.json` и синхронизируется двухфазным `tools/sync.py`. Ниже сохранён смысл полей без повторения полной спецификации валидатора.

Колонки делятся на обязательные, физические, детерминированные, процентильные и переходные. Пустое значение в необязательной колонке означает «взять из пресета».

#### Идентичность и редакционный статус

| Колонка | Тип | Обязательность | Смысл |
|---|---|---|---|
| `place_id` | текст | да | Точное значение `places.ID`, уникально |
| `profile_status` | enum | да | `draft`, `review`, `frozen`, `disabled` |
| `profile_revision` | целое ≥1 | да | Редакционная ревизия профиля |
| `preset_id` | текст | да | Например, `earthlike_balanced` |
| `surface_class` | enum | да | `terrestrial`, `ocean`, `desert`, `ice`, `volcanic`, `barren`, `gas_giant`, `no_surface` |
| `notes_admin` | текст без переносов | нет | Короткая служебная заметка |

#### Физические и визуальные параметры

| Колонка | Тип | Обязательность | Смысл |
|---|---|---|---|
| `radius_km` | число >0 | для freeze — да | Радиус тела; определяет число ячеек |
| `axial_tilt_deg` | 0–180 | нет | Наклон оси для ориентации/освещения |
| `rotation_period_hours` | число >0 | нет | Только скорость/характер вращения, если будет использоваться |
| `palette_id` | текст/код | нет | Визуальная палитра; не должна менять географию |

#### Детерминированность и заморозка

| Колонка | Тип | Кто заполняет | Смысл |
|---|---|---|---|
| `master_seed_hex` | текст, 16 hex | инструмент или админ один раз | Unsigned 64-bit seed |
| `grid_version` | текст | инструмент при freeze | Версия топологии и адресации |
| `noise_version` | текст | инструмент при freeze | Версия шума и seed splitting |
| `geography_version` | текст | инструмент при freeze | Версия полей/континентов/гидрологии |
| `preset_version` | текст | инструмент при freeze | Версия раскрытых значений пресета |
| `generation_key` | текст | **только инструмент** | Хэш полного эффективного манифеста |
| `approved_by` | текст | админ | Кто утвердил freeze |
| `approved_at` | дата/текст ISO | админ/инструмент | Когда утверждён freeze |

#### Целевые масштабы доменов

| Колонка | Стартовое значение | Смысл |
|---|---:|---|
| `continent_mean_cells` | 400 для `earthlike_balanced` при v=128 | Средний эффективный размер идентичности |
| `continent_variation` | 0.8 для `earthlike_balanced` | Целевой разброс эффективных масс; в админском интерфейсе можно скрыть за пресетом |
| `ocean_basin_mean_cells` | 6000 для `earthlike_balanced` при v=128 | Средний эффективный размер океанического бассейна |
| `drainage_mean_cells` | 72 для `earthlike_balanced` при v=128 | Целевой ориентир водосбора; фактические водосборы строит Этап 5 |

#### Процентильные пороги

Все значения — числа от 0 до 100. Пусто означает пресет.

| Колонка | Смысл |
|---|---|
| `ocean_pctl` | Процентиль высоты, ниже которого начинается океан; 70 означает примерно 70% площади ниже уровня моря |
| `shelf_below_pctl` | Нижняя граница шельфовой переходной зоны |
| `shelf_above_pctl` | Верхняя граница береговой переходной зоны |
| `highland_land_pctl` | Начиная с какого процентиля высоты суши считать возвышенность |
| `mountain_land_pctl` | Начиная с какого процентиля высоты суши считать горы |
| `arid_land_pctl` | Ниже какого процентиля влажности суша считается засушливой |
| `wet_land_pctl` | Выше какого процентиля влажности суша считается влажной |
| `cold_pctl` | Нижний температурный порог в процентильной калибровке |
| `hot_pctl` | Верхний температурный порог |
| `stream_flow_pctl` | Начиная с какого процентиля накопленного стока рисовать поток |
| `major_river_flow_pctl` | Начиная с какого процентиля поток считается крупной рекой |

Важная семантика: процентили считаются **с весами фактических площадей ячеек**, а не просто по количеству строк. Для порогов суши знаменатель — только суша; для океана — вся поверхность. Эти правила должны быть записаны в контракте и не меняться молча.

#### Переходы

| Колонка | Единица | Смысл |
|---|---|---|
| `coast_soft_width_cells` | ячейки, дробное | Мягкость берега и шельфа |
| `continent_soft_width_cells` | ячейки, дробное | Размытие континентальных идентичностей |
| `biome_soft_width_cells` | ячейки, дробное | Размытие биомных границ |
| `transition_entropy_pctl` | 0–100 | Какая верхняя доля смешанных ячеек выделяется как явная переходная зона в диагностике/подсветке |

### 8.4. Пресеты вместо ручного заполнения всех чисел

Админу нельзя предлагать вручную заполнять 30 чисел на каждую планету. Базовый путь:

1. Выбрать `preset_id` и `surface_class`.
2. При необходимости указать радиус.
3. Получить seed от инструмента.
4. Посмотреть предпросмотр и статистику.
5. Менять процентили только как исключение.

Стартовые пресеты для проектирования:

- `earthlike_balanced`;
- `earthlike_archipelago`;
- `ocean_world`;
- `desert_dry`;
- `ice_world`;
- `volcanic_active`;
- `barren_moon`;
- `gas_giant_bands` — без поверхности и локальной карты.

Пресет должен быть версионирован. При freeze в манифест попадают **раскрытые эффективные значения**, а не только имя пресета. Иначе будущая правка пресета молча изменит уже утверждённую планету.

### 8.5. Эффективный манифест генерации

Перед вычислением ключа профиль превращается в канонический манифест:

```json
{
  "place_id": "2",
  "profile_revision": 3,
  "surface_class": "terrestrial",
  "radius_km": 6371,
  "grid_version": "goldberg-gp-v1",
  "noise_version": "planet-noise-simplex3d-v1",
  "geography_version": "c100-soft-v2",
  "preset_id": "earthlike_balanced",
  "preset_version": "planet-presets-v1",
  "master_seed_hex": "9f3ac41d72e08b10",
  "continent_mean_cells": 400,
  "ocean_pctl": 70.0
}
```

Пример сокращён. В реальном манифесте должны присутствовать все эффективные параметры после применения пресетов и значений по умолчанию.

Канонизация:

- UTF-8;
- ключи JSON отсортированы;
- числа приведены к зафиксированной точности;
- пустые значения уже раскрыты из пресета;
- имя, фракция, описание и источник **не входят** в географический манифест;
- палитра входит в отдельный render-манифест, чтобы смена цвета не считалась изменением местности.
