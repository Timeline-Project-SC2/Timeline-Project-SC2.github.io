## 2. Что изменено в коде

1. `src/atlas/sector-areas-editor-ui.ts` — `data-action="expand"` вызывает `setScreen('dependencies')`
   вместо одного `setCollapsed(false)`; `syncShellEdges()` меряет внешние границы `.topbar`
   и задаёт `--shell-left`, `--shell-right`, `--shell-inset-top`; `destroy()` снимает новую
   переменную. Правка от предыдущего агента подтверждена прогоном, формула верхнего inset
   оставлена в координатах сцены и снабжена комментарием-обоснованием.
2. `site/sector/admin-edit/admin-edit.css` — верхний inset оболочки переведён на
   `var(--shell-inset-top, 8px)`; добавлены три блока в конце файла:
   - телефонная свёртка `#adminEditorPanel.is-collapsed` целиком через `inset: auto 8px auto auto`
     (прежнее правило на классах проигрывало общей оболочке по специфичности);
   - явное подчинение экранных правил свёртке (на `dependencies` док перекрывал рейл);
   - на телефоне в свёртке скрыты навигация и полоса инструментов — на десктопе пять быстрых
     иконок сохранены, как требует владелец.
3. `tests/sector-areas-editor-ui.test.mjs` — старый тест рёбер переписан под `.topbar` (заглушки
   `#toggleSidePanel`/`.brand-emblem` нарочно отдают другие числа, чтобы возврат старого ориентира
   ломал тест), добавлены проверка минимума 8 px, телефонного случая, регрессия рейла
   `properties → collapse → expand = dependencies`, а также CSS-регрессии специфичности.

```bash
npm run build && python3 -m http.server 8080 --directory .publish &
LD_LIBRARY_PATH=/tmp/al2023/lib node admin-ui-browser-check.mjs --prefix=after
```
