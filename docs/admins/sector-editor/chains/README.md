# Цепочки связей между модулями

Модуль сам по себе ничего не объясняет: смысл в том, **что куда передаётся**. Здесь
четыре сквозные цепочки, по одной на каждый маршрут данных. Каждый шаг — ссылка на
модуль и одной строкой то, что он отдаёт следующему.

| Цепочка | Маршрут | О чём |
|---|---|---|
| [Правка → документ](edit-to-document.md) | ввод → команды → документ → проверка → черновик | как щелчок и штрих становятся записью в документе |
| [Документ → пиксели](document-to-paint.md) | документ → каскад → цвет/градиент → LOD → отрисовка | как запись становится цветом на карте |
| [Границы → полосы и гало](bounds-to-paint.md) | границы сектора → полосы → scope → обрезка гало | как пространство сектора задаёт классификацию |
| [Журнал и сохранение](save-and-log.md) | документ → журнал → черновик → выгрузка | что попадает в историю и что уходит в файл |

Наверх: [карта модулей](../README.md).
