# Цепочка: документ → пиксели

Как запись в документе становится цветом на карте и в предпросмотре.

## Шаги

1. **Состояния** — [каскад](../modules/cascade.md) собирает эффективные состояния:
   свои и унаследованные по `parentId`, для текущего режима и уровня.
2. **Цвет** — [палитра](../modules/color.md) даёт стиль состояния: заливку, обводку,
   прозрачность; область без фракций получает `NEUTRAL_COLOR`.
3. **Градиент** — [градиент](../modules/gradient.md) превращает `GradientSpec`
   в цвета вершин; при отсутствии спецификации работает `autoStops`.
4. **Перекрытия** — [форс](../modules/force.md) накладывает ручные правки:
   `resolvePaint` решает, что победило, `paintOrder` задаёт порядок слоёв по `z`.
5. **Упрощение** — [LOD](../modules/lod.md) режет вершины под текущий масштаб,
   не меняя документ.
6. **Список к отрисовке** — [отрисовка](../modules/render.md) собирает `AreaPaint`;
   пиксели ставит общий рендерер карты.

## Что важно помнить

Предпросмотр «было → стало» идёт по этому же маршруту, но с копией документа:
исходные данные и базовое состояние карты не меняются, снятие флажка возвращает
картинку без промежуточной записи.
