# `sector-bounds-edit` — правка линий границ сектора

Плоскость: **пространственное влияние** · статус в панели: **рабочий** ·
файлы: `src/atlas/sector-bounds-edit.ts` (ядро), `src/atlas/sector-bounds-edit-ui.ts` (UI).

## Что берёт

Контуры из `data/sector-bounds.json` ([`sector-bounds`](sector-bounds.md)) и
клики/жесты на стадии карты: выбор сегмента, двойной клик, перетаскивание ядра.

## Что отдаёт

- сессию правки `BoundsEditSession`: документ, журнал `past`/`future`, активную
  правку и выбор сегмента;
- команды: `beginBoundsEdit`, `moveBoundsEditCore`, `commitBoundsEdit`,
  `cancelBoundsEdit`, `undoBoundsEdit`, `redoBoundsEdit`;
- выбор сегмента по клику: `pickBoundsEdge`;
- якоря: `anchorsForEdge` — 5 равномерных точек по сегменту;
- интервал влияния: `influenceIntervalFor`;
- деформацию: `deformEdge` / `deformEdgeAt` — плавный булмп к ядру;
- экспорт/импорт: `serializeBoundsEdit` / `parseBoundsEdit` — та же схема, что
  `data/sector-bounds.json`.

## Модель деформации (точная математика)

- сегмент между двумя соседними вершинами — прямая в параметре `t ∈ [0, 1]`;
- **5 якорей** равномерно по сегменту: `t = 0,1; 0,3; 0,5; 0,7; 0,9` — опорные
  точки, которые **не смещаются** при движении ядра;
- концы сегмента — структурные вершины (сообщаются с соседними сегментами),
  фиксированы всегда;
- **ядро** — отдельная точка; перетаскивание тянет контур в сторону ядра;
- **границы влияния**: интервал между двумя якорями, которыми ядро окружено;
  вне интервала смещение строго ноль, на якорях — ноль;
- функция смещения: `smoothstep` — нули на концах интервала, единица в ядре;
  смещение каждой точки = `(ядро − P(t_ядро)) · shape(t)`;
- коммит: сегмент заменяется 16-точечной кривой, концы которой совпадают с
  концами исходного сегмента; замкнутые контуры остаются замкнутыми, гало —
  открытым.

## Кто использует

Раздел «Линии» в панели редактора (overlay-предпросмотр, ввод с стадии карты,
Ctrl+Z/Ctrl+Shift+Z, экспорт JSON); редактор областей отдаёт Ctrl+Z, когда
линейная правка активна.

## Что важно помнить

Правка работает **локально**: двигается только интервал ядерного влияния.
Повторный двойной клик заменяет правку, Escape отменяет предпросмотр (документ
не трогается). Ядро обрезается по границам поля (0…10000), поэтому коммит
всегда даёт корректный документ. Права на запись в репозиторий и публикацию
нет — правка лежит в браузере и выгружается файлом.
