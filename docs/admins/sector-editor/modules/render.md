# `sector-areas-render` — отрисовка областей

Плоскость: **порядок отрисовки** · статус в панели: **рабочий** ·
файл: `src/atlas/sector-areas-render.ts`.

## Что берёт

Документ, уровень детализации ([LOD](lod.md)), палитру ([цвет](color.md)),
градиент ([градиент](gradient.md)) и перекрытия ([форс](force.md)).

## Что отдаёт

- `buildAreaPaints` → список `AreaPaint` с цветами колец и порядком;
- `vertexCss` — цвет конкретной вершины для градиента;
- `areaSize` — площадь области в единицах карты (используется в свойствах).

## Кто использует

Общий рендерер карты (`canvas-renderer.ts`), сцена сектора (`sector-scene.ts`) и
[панель](panel.md) — для предпросмотра «было → стало».

## Что важно помнить

Это **не второй рендерер**: модуль только считает, что рисовать. Пиксели ставит
общий рендерер карты, поэтому предпросмотр и живая карта не расходятся.
