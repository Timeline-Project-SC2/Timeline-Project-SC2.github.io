# `sector-areas-color` — палитра режимов

Плоскость: **порядок отрисовки** · статус в панели: **только просмотр** ·
файл: `src/atlas/sector-areas-color.ts`.

## Что берёт

Режим и состояние области; палитру фракций (`parseFactionCsv`) для окраски по владельцу.

## Что отдаёт

- стили режимов `MODE_STYLES`, `modeStyle` и задач `TASK_STYLES`, `taskStyle`;
- итоговый стиль состояния `stateStyle` (цвет заливки, обводки, прозрачность);
- нейтральный цвет `NEUTRAL_COLOR` — он же цвет области без фракций;
- работу с цветом: `mixRgb`, `lighten`, `toCss`, `rgbToHsl`, `hslToRgb`, `strokeSafeColor`;
- фокус: `focusAppearance`, `DEFAULT_FOCUS_SETTINGS`.

## Кто использует

[Форс](force.md) — цвет перекрытия; [градиент](gradient.md) — акцент режима;
[отрисовка](render.md) — цвет колец; общий рендерер карты.

## Что важно помнить

Нейтраль — не «пустое значение», а осознанное решение: область без `factionIds`
рисуется нейтральным цветом, а не выпадает из отрисовки.
