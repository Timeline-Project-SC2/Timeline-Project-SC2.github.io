## 12. Сдача

```bash
git diff --check
python3 tools/planet_generation.py validate --profiles ... --places data/places.csv
gh pr create --base main --head <ветка> --title "docs(<планета>): пре-сиды ..." --body "..."
gh pr checks <номер>
```

Дождись зелёных проверок `Сборка`, `Скрипты сайта`, `Planet CPU
performance` и только потом докладывай. Не сливай PR без просьбы.
Если PR уже открыт на ту же ветку — не открывай второй, добавь коммит и
комментарий.

## Крутилки и их эффект

| Поле | Что меняет |
|---|---|
| `master_seed_hex` | рисунок континентов и рельефа; климат — нет |
| `ocean_pctl` | уровень моря: больше — больше воды |
| `shelf_below/above_pctl` | полоса шельфа вокруг уровня моря (порядок `below ≤ ocean ≤ above`) |
| `arid_land_pctl` / `wet_land_pctl` | порог сухости и влажности: шире разрыв — мягче переходы |
| `cold_pctl` / `hot_pctl` | границы холодного и жаркого поясов |
| `mountain_land_pctl` | реже/чаще горы (выше — реже) |
| `highland_land_pctl` | начало высокогорья (`≤ mountain`) |
| `continent_mean_cells` / `continent_variation` | размер и разброс материков |
| `ocean_basin_mean_cells` | размер океанических бассейнов |
| `drainage_mean_cells` | размер речных регионов |
| `stream_flow_pctl` / `major_river_flow_pctl` | порог ручьёв и крупных рек |
| `*_soft_width_cells` | мягкость берега, континентов, биомов |
| `surface_class` | множители биомов (см. шаг 3) |
| `radius_km` | каноническая частота сетки, а значит плотность ячеек |

## Критерии приёмки

- [ ] Профиль существует в коде: все 19 чисел явные, порядки процентилей
      соблюдены (`shelf_below ≤ ocean ≤ shelf_above`, `highland ≤ mountain`,
      `arid ≤ wet`, `cold ≤ hot`, `stream ≤ major_river`).
- [ ] `validate` для каждого файла строки: `0` ошибок и `0` предупреждений.
- [ ] Ключ `PG1` получен CLI, а не самописным скриптом.
- [ ] На одно `place_id` — не больше одной строки во всех файлах.
- [ ] Метрики мира соответствуют лору (джунгли/вода/вулканика/горы).
- [ ] Композиция карты соответствует R2: океан там, где на референсе;
      лёд только в шапке; шельф читается; горы — цепями, а не крупой.
- [ ] Геометрия не зеркалится: точка с `lon > lon0` справа от центра.
- [ ] На карте нет веерных лучей у края, ромбовидных «лучей» шельфа,
      ступенек берега от ячеек и белых заливок внутри суши.
- [ ] Подписи читаемы на любом фоне, не наезжают друг на друга и на край.
- [ ] Картинки: портрет/глобус, три ракурса, подписанная карта, обзорный
      лист; артефактов нет.
- [ ] В README явно сказано: пре-сид, `review`, картинки — иллюстрация,
      а не данные; каноническая частота и фактическая `v` указаны.
- [ ] CI зелёный, PR открыт.

## Грабли (проверено на практике)

**Данные и строки**

1. Валидатор **запрещает два профиля на один `place_id`** — три варианта
   это три отдельных файла-альтернативы, а не три строки в одном CSV.
2. Если планета уже есть в `data/places.csv`, `places.example.csv`
   **не нужен**: валидируй прямо против `data/places.csv` с `--place-id`.
   Заглушка нужна только для выдуманных мест.
3. `place_id` обязан существовать в `places`, иначе `validate` падает.
4. Страница `/planet-globe/` строит профиль **из значений пресета**, а не
   из строки CSV. Ссылка с `?preset=…&seed=…` показывает характер мира,
   но не воспроизводит вашу строку, если числа отличаются от пресета.
5. Нормы «в ячейках» действительны для канонической частоты; при
   генерации на `v=64/96/256` их надо масштабировать, иначе континенты и
   реки выйдут другого физического размера.
6. `expectedFrequency(6300) = 127`, `expectedFrequency(6200) = 125`,
   `expectedFrequency(6500) = 130` — не пиши «125 для 6300».
7. CSV пишите с LF: `.gitattributes` нормализует переводы строк, иначе
   `git diff --check` ругается на CRLF.
8. `palette_id` проверяется только на формат и **не влияет** на рендер —
   это задел под `planet_customizations`. Не обещайте, что палитра
   применится.

**Геометрия и рендер**

9. `GeodesicGrid.build(v)` (не `buildGrid`). Адреса ячеек привязаны к `v`.
10. `surface.lakes[]` → `representativeCell`, `drainageRegions[]` →
    `outletCell`; других полей там нет.
11. `buildEquirectPreview` даёт артефакты у полюсов — для карт пиши свой
    рендер.
12. **Зеркало камеры**: `east = cross(center, up)`, `north = cross(east,
    center)`. Обратный порядок = зеркальная карта. Проверка одной точкой
    обязательна.
13. **Эквиректангулярное окно lon/lat как «регион» не годится**: регион
    шире полушария, края дублируются, у полюсов веер. Только азимутальная
    проекция + `fill > 1.8`.
14. **Поворот кадра важнее центра**: при `rotDeg` от 90° ледяная шапка
    уезжает вбок, и «север сверху» теряется. Для планет с шапкой — `rot 0`.
15. **Океан по глубине даёт кольца** вокруг берега; шельф считай по
    расстоянию до суши, шамферной картой расстояний.
16. **BFS-4 для расстояний даёт ромбы и лучи** от берега — только
    шамферная (диагональ `√2`) или евклидова.
17. **Маска суши по z-буферу даёт ступеньки** размером в ячейку. Считай
    покрытие с весами и сглаживай маску до композита.
18. **`polar_ice` на всей суше заливает карту белым**: лёд — только
    `|lat| ≥ 66` и высокие пики, остальные холодные биомы — тундра/степь.
19. **`mountainWeight` не сглаженный** = крупа из одиночных ячеек. Три
    итерации по соседям превращают её в цепи.
20. **Мелкие озёра** (десятые доли процента) в региональном масштабе
    превращают карту в крапинку — рисуй только крупные (≥160 ячеек).
21. **Двойное затемнение на глобусе**: цвет суши уже содержит рельефную
    подсветку, сверху нужен только сферический свет.
22. **Попиксельный поиск ближайшей ячейки** — 168 s на картинку.
    Сплат + композит + карта расстояний дают 8–9 s.
23. **Спектральная «дымка» у лимба** на глобусе съедает цвет — не
    добавляй её поверх палитры, ограничься свечением вне диска.
24. Вращайте мир, а не камеру, когда делаете несколько ракурсов.
25. На равнопромежуточной развёртке у полюсов остаются пустые строки —
    заполняйте интерполяцией, иначе в отчёте будут чёрные шапки.

**Подписи и оформление**

26. В контейнере нет italic-шрифта — наклоняй глифы аффинным сдвигом,
    не заменяй шрифт на «похожий».
27. Без ореола подпись исчезает на лесу и горах; ореол — половина
    читаемости.
28. Три подписи с одинаковым смещением садятся друг на друга — разводи
    по кругу.
29. Красивая картинка ≠ данные: палитра и дымка — оформление, географию
    подтверждают только метрики из `planet-surface`.
