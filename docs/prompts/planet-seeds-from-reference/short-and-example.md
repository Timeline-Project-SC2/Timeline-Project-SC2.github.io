# Пре-сиды: короткая версия и пример Зеруса

>
> Источник: [`docs/prompts/planet-seeds-from-reference.md`](../planet-seeds-from-reference.md) · строки 517–591.
> Назад: [карта документации](../../README.md) · [индекс документации](../../README.md).

## Формат ответа

1. **Что сделано** — 3–5 строк.
2. **Таблица вариантов** — seed, характер, суша, хребты, озёра, ключ.
3. **Файлы** — путь и назначение каждого.
4. **Проверки** — команды и результат (validate, CI).
5. **Что важно знать** — заглушки, ограничения, что решает владелец.
6. **Вопрос** — какой вариант брать и что подкрутить.

## Короткая версия (copy-paste)

```text
Ты — инженер процедурной генерации планет в Timeline-Project-SC2.
Задача: пре-сиды планеты <ИМЯ> по референсу и лору.

Входы: картинка <путь> (R1 — портрет планеты | R2 — карта региона),
лор <текст>, режим <A — пре-сид без привязки к эталону | B — подгонка
по метрике | C — только строки>.
Не менять код сайта, не замораживать профиль, не сливать PR без просьбы.

1) Прочитай AGENTS.md, src/contracts/planet-generation-contract.json,
   tools/planet_generation.py, docs/ADMIN_GUIDE.md, BIOME_DEFINITIONS.
   Уточни expectedFrequency(radius): 6200→125, 6300→127, 6500→130.
   Найди планету в data/places.csv — если есть, работай с её ID.
2) Разбери референс. R1: центр/радиус диска, терминатор, дымка, доли
   воды/суши/горячих зон. R2: полосы воды/суши/льда, ширина шельфа,
   палитра по квантилям, все подписи дословно.
3) Профиль: preset_id, surface_class и все 19 географических чисел явно.
   volcanic = растительность ×0.65; лес 0.44 ≈ wet 58 / arid 14 / cold 24;
   горы 84–88; суперконтинент = continent_mean_cells 800–1000.
4) Сгенерируй 12–20 seed'ов модулями geodesic-grid/planet-geography/
   planet-surface в Node на v=48…96, отбери 4–8 по метрикам.
5) Если R2 — подбери кадр: азимутальная проекция, maxDeg 68–78, fill 2.0,
   east = cross(center, up), north = cross(east, center); перебери центры
   и поворот по композиционному скору (вода слева, суша справа,
   лёд в шапке), посмотри топ-4 глазами.
6) Рендер: суша от биомов + сглаженный mountainWeight; лёд только |lat|≥66
   и пики; вода от расстояния до суши (шамферная карта), shelfPx 0.035–0.05
   ширины; реки streamWeight>0.68; маска суши по покрытию + сглаживание;
   суперсэмплинг 2×. Бюджет: 1500×960 ≈ 8–9 с на v=256.
7) Сделай глобус/портрет, три ракурса (вращай мир), карту с подписями
   (serif, наклон shear 0.22, ореол), обзорный лист с референсом.
8) Посчитай якоря: шапка, хребты (крупнейший + дальний), озеро, лес,
   уникальный объект, 3 улья farthest-point sampling. Координаты + lat/lon.
9) Три финалиста с разным характером. CSV в каноническом заголовке,
   profile_status=review, все версии явно, LF. Ключ — только CLI key.
   validate против data/places.csv: 0 ошибок, 0 предупреждений.
   На одно place_id — одна строка.
10) docs/<папка>/README.md + assets/, PR, зелёный CI.
    Тайны не раскрывать как факт.

В ответе: что сделано, таблица вариантов с ключами, файлы, проверки,
ограничения (review, картинки — иллюстрация), вопрос «какой вариант берём».
```

## Пример 1: Зерус (R1, 21.10.2026)

- Референс: beauty-рендер планеты в оранжевой туманности, диск
  `center ≈ (621, 241)`, `r ≈ 186 px`, терминатор справа-снизу.
- Лор: джунгли, океаны, вулканизм, жарко и влажно; объекты — Первый
  нерестовый бассейн, Вечный шрам, Фулмические нагорья, Расколотая
  долина, Неукротимый шпиль, Нестабильная расщелина.
- Режим: `A` (пре-сид и кастомизация без привязки к эталону).
- Итог: `docs/zerus/` — три варианта, `place_id=1000` (заглушка),
  строки `planet-generation.row-{A,B,C}.csv`, ключи
  `PG1-CS6VOKORWX3SOFJXEEAMQ6CBGI`,
  `PG1-ZVIDIB7745BMRBD5YSKYHB2MRM`,
  `PG1-PHNVBJMYKXHOTA4SSL5EO4B2GY`.
- Что оказалось важным: вулканический биом — доли процента, вулканизм
  виден по `mountainSeamWeight` и `volcanism`; развёртка с пустыми
  полюсами; вращение мира, а не камеры.
