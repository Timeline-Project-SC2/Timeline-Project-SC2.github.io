# Валинор — пре-сиды планетной генерации

> **Дата:** 21 октября 2026.
> **Статус:** пре-сид для `planet_generation` (черновик уровня `review`).
> Это **не** заморозка: строки подготовлены мной, владелец вставляет их
> в Google Sheets сам.

Валинор уже есть в таблице мест — `places.csv`, `ID=3`, `system_id=8`,
«Столица народа Нолдор. Аграрная сельскохозяйственная планета».
Поэтому здесь нет `places.example.csv`: все три строки ссылаются на
существующий `place_id=3`, внешний ключ закрыт.

Референсы — два изображения заказчика:

* `assets/reference-region.png` — beauty-карта региона: тёмно-синий океан
  слева, широкая бирюзовая отмель вдоль берега, зелёная суша с подсветкой
  рельефа, бурые горные цепи, белая шапка `Helcenar` на севере, голубые
  реки, подписи `Helcenar`, `Firinetële`, `Noralya`, `Laurietia`,
  `Hisilomë` итальянским курсивом;
* вторая схема (композиция планеты): океан и затопленный западный материк
  слева, суперконтинент с 3–4 цепями и лесами на юго-востоке справа.

Сиды **не подгонялись под точное расположение пятен** на референсе — задача
была дать несколько независимых воспроизводимых миров с характером Валинора
и полный набор строк для таблицы. Совпадают композиция (океан слева,
суперконтинент в правых двух третях, ледяная шапка сверху, широкий шельф,
бурые цепи, реки), а не пиксели.

## 1. Что лежит в этой папке

География всех картинок посчитана **тем же кодом**, что и боевой глобус
(`geodesic-grid` → `planet-geography` → `planet-surface`), напрямую в Node
на `v=256` (655 362 ячейки; каноническая частота для 6300 км — `v=127`,
то есть картинки вдвое подробнее боевой сетки). Рисунок — мой рендер:
палитра, подсветка рельефа и свечение это оформление визуализации, а
рельеф, биомы, реки, озёра и горы — чистый выход генератора. Это
«примерная визуализация», а не превью сайта.

## 2. Общий профиль

Все 19 географических чисел заполнены явно, чтобы строка не зависела от
будущих правок пресета:

```text
radius_km=6300
continent_mean_cells=900   continent_variation=0.55
ocean_basin_mean_cells=9000   drainage_mean_cells=64
ocean_pctl=50   shelf_below_pctl=44   shelf_above_pctl=60
highland_land_pctl=72   mountain_land_pctl=86
arid_land_pctl=14   wet_land_pctl=58   cold_pctl=24   hot_pctl=70
stream_flow_pctl=88   major_river_flow_pctl=99
coast_soft_width_cells=4.0   continent_soft_width_cells=3.0
biome_soft_width_cells=2.0   transition_entropy_pctl=90
```

Почему так:

* крупные континентальные ядра (`continent_mean_cells=900` при разбросе
  0.55) дают **суперконтинент**, а не архипелаг — по лору три плиты
  слились в одну;
* `ocean_pctl=50` отдаёт под воду примерно половину поверхности, при этом
  `shelf_below_pctl=44` / `shelf_above_pctl=60` делают отмель широкой —
  это и есть бирюзовая кайма вдоль берега и «затопленный запад»;
* `mountain_land_pctl=86` держит горы редкими, но высокими: около
  24–28 хребтов на планете и 3–4 крупных на кадр — «три цепи между
  плитами»;
* `cold_pctl=24` при `wet_land_pctl=58`, `arid_land_pctl=14` даёт лес
  около 0.43 доли суши и ледяную шапку 0.14 всей поверхности;
* `transition_entropy_pctl=90` размывает границы биомов, поэтому суша
  выглядит пятнами, как на референсе, а не полосами.

## 4. Якоря под лор

Координаты — широта/долгота реальных ячеек генератора из выбранного кадра
(`variant.json` → `anchors`). Имена взяты с референса; раскладка по лору
такая:

| Имя | Что это по лору | A (шир., долг.) |
|---|---|---|
| `Helcenar` | северная плита, средняя −45 °C, снег, раз в год одна буря, ледяная стена ~4 км | 67.2°, −74.6° |
| `Laurietia` | северная цепь-шов между Северной и Южной плитами | 40.5°, −87.8° |
| `Hisilomë` | южная цепь на краю затопленной Западной плиты | 20.7°, −98.5° |
| `Noralya` | крупнейшее озеро южной плиты (219 ячеек) | 26.6°, −81.8° |
| `Firinetële` | лесной массив юго-востока: «арбуз + малина + черника» | 18.8°, −37.3° |
| `Valitindò` | единственное место добычи камней Valitindò — изолированный высокий массив | 66.3°, −58.9° |
| `Ulaia I–III` | три пещерных улья «безымянных тварей», максимально разнесённые | см. `anchors.hives` |

Почему именно так: горные якоря — представительные ячейки крупнейших
хребтов из `surface.mountainRanges`, озеро — самое большое из
`surface.lakes`, лес — самый плотный южный массив, ульи — три горные
ячейки, максимально удалённые друг от друга и от `Valitindò` (в пещерах
жили, а не добывали камень). Порядок и имена — редакционное решение,
генератор о них не знает.

## 5. Как проверялось

```bash
python3 tools/planet_generation.py validate \
  --profiles docs/valinor/planet-generation.row-A.csv \
  --places data/places.csv
# OK: профилей проверено: 1; предупреждений: 0
```

Ключи `generation_key` посчитаны тем же валидатором:

| | `generation_key` |
|---|---|
| A | `PG1-GE7SGNXHPL7ZDSLGV3V5STUUGQ` |
| B | `PG1-UFTQRXO2STT5WLZUUBOQHIQMXM` |
| C | `PG1-4H7LE4YO6VIOPIYT4HL7RRHYV4` |

Палитры (`valinor_glacier_teal`, `valinor_ash_teal`,
`valinor_glacier_white`) — только имена для render-манифеста, в
`generation_key` они не входят, как и наклон с периодом вращения.

## 6. Ограничения

* Картинки — мой рендер, а не `/planet-globe/`: у страницы своя палитра,
  освещение и камера.
* Точность рельефа ограничена сеткой `v=256`; на карте региона одна
  ячейка ≈ 1.9 px, поэтому берег сглажен, а не «ступеньками».
* `Hisilomë` в вариантах A и C — маленький хребет (7 и 3 ячейки), потому
  что южная цепь на кадре почти вся ушла под воду: это как раз
  «затопленный запад» из лора, но подпись стоит на оставшемся над водой
  гребне.
